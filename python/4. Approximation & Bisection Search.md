# 🔢 Floating-Point Numbers & Approximation in Python

## Absolute Value

The `abs()` function returns the **absolute (positive) value** of a number.

```python
num = -10

num = abs(num)

print(num)   # 10
```

---

# ⚠️ Surprising Result with Floats

```python
x = 0

for i in range(10):
    x += 0.1

print(x == 1)
print(x, "==", 10 * 0.1)
```

**Output**

```text
False
0.9999999999999999 == 1.0
```

### Why?

- Floating-point numbers are stored in **binary**.
- Some decimal values (like `0.1`) **cannot be represented exactly**.
- Tiny rounding errors accumulate.

> [!WARNING]
> **Never use `==` to compare floating-point numbers.**

Instead, compare whether they are **close enough**.

```python
epsilon = 1e-6

if abs(x - 1) < epsilon:
    print("Equal")
```

---

# Approximation

Approximation means finding an answer that is **close enough** instead of exact.

Example:

Find the square root of `x` such that:

```text
|guess² - x| < epsilon
```

where **epsilon** is a very small error value.

---

## Approximation Algorithm

1. Start with a small guess.
2. Increase the guess by a tiny amount.
3. Check if `guess²` is close enough to `x`.
4. Stop when the error is smaller than `epsilon`.

---

## Implementation

```python
x = 36
epsilon = 0.01
guess = 0.0
increment = 0.0001
num_guesses = 0

while abs(guess**2 - x) >= epsilon:
    guess += increment
    num_guesses += 1

print("num_guesses =", num_guesses)
print(guess, "is close to square root of", x)
```

---

# Why Doesn't It Work for Large Numbers?

Example:

```python
x = 54321
```

Using

```python
increment = 0.0001
```

the program must perform **millions of iterations** before reaching the square root (≈233.07).

This makes the algorithm **extremely slow**.

To avoid an infinite loop, we add another condition:

```python
guess**2 <= x
```

---

## Improved Implementation

```python
x = 54321
epsilon = 0.01
guess = 0.0
increment = 0.0001
num_guesses = 0

while abs(guess**2 - x) >= epsilon and guess**2 <= x:
    guess += increment
    num_guesses += 1

print("num_guesses =", num_guesses)

if abs(guess**2 - x) >= epsilon:
    print("Failed on square root of", x)
else:
    print(guess, "is close to square root of", x)
```

---

> [!TIP]
> Approximation using small increments is simple but **very inefficient** for large numbers. Algorithms like **bisection search** and **Newton's method** are much faster.

---

## Quick Revision

- `abs(x)` → Absolute value.
- Floats are **approximate**, not exact.
- ❌ Don't compare floats using `==`.
- ✅ Compare using `abs(a - b) < epsilon`.
- Approximation finds an answer **within an acceptable error (`epsilon`)**.
- Exhaustive approximation becomes **very slow** for large numbers.

# 🔍 Bisection Search

## What is Bisection Search?

**Bisection Search** is an efficient searching technique used when the possible answers are **ordered**.

Instead of checking every value one by one, it repeatedly **divides the search space into two halves**, making it much faster than brute-force search.

---

## How It Works

1. Define the search interval (`low` and `high`).
2. Find the midpoint.
3. Compare the midpoint with the target.
4. Keep only the half that can contain the answer.
5. Repeat until the answer is close enough.

> [!TIP]
> At each step, the search space is cut in **half**.

---

## Algorithm

```text
1. Set low and high.
2. Find the middle value.
3. If guess² is too small:
       move low to guess.
4. Otherwise:
       move high to guess.
5. Repeat until the error is less than epsilon.
```

---

# Example: Square Root using Bisection Search

```python
x = 54321
epsilon = 0.01

low = 0
high = x

guess = (low + high) / 2
num_guesses = 0

while abs(guess**2 - x) >= epsilon:

    if guess**2 < x:
        low = guess
    else:
        high = guess

    guess = (low + high) / 2
    num_guesses += 1

print("num_guesses =", num_guesses)
print(guess, "is close to square root of", x)
```

---

# Why is Bisection Search Better?

### Brute Force

- Checks every possible value.
- Search space decreases like:

```text
N
N - 1
N - 2
...
```

Time Complexity:

```text
O(N)
```

---

### Bisection Search

- Removes **half** the search space every iteration.

Search space:

```text
N
N/2
N/4
N/8
...
```

Time Complexity:

```text
O(log₂N)
```

---

## Example

Finding √54321

| Method | Number of Guesses |
|---------|------------------:|
| Brute Force | 23,000,000+ |
| Bisection Search | ~30 |

> Bisection Search is **thousands of times faster**.

---

# Why is it Logarithmic?

After each step:

```text
1st guess → N / 2
2nd guess → N / 4
3rd guess → N / 8
...
kth guess → N / 2^k
```

When only one value remains:

```text
N / 2^k = 1
```

Rearranging:

```text
N = 2^k

k = log₂(N)
```

Therefore,

```text
Time Complexity = O(log₂N)
```

---

# Analogy

Imagine students are seated in **alphabetical order**.

To find **Rahul**:

- Ask the student in the **middle**.
- If the middle student's name comes before Rahul,
  ignore the first half.
- Otherwise,
  ignore the second half.

Repeat until Rahul is found.

This is exactly how **Bisection Search** works.

---

# Does It Always Work?

❌ No.

If

```python
0 < x < 1
```

Example:

```python
x = 0.5
```

Searching from

```text
0 → 0.5
```

doesn't work because

```text
√0.5 ≈ 0.707
```

which is **outside** the search interval.

---

# Bisection Search for All Values of x

```python
x = 0.5
epsilon = 0.01

if x >= 1:
    low = 1.0
    high = x
else:
    low = x
    high = 1.0

guess = (low + high) / 2

while abs(guess**2 - x) >= epsilon:

    if guess**2 < x:
        low = guess
    else:
        high = guess

    guess = (low + high) / 2

print(f"{guess} is close to square root of {x}")
```

---

# Observations

- ✅ Much faster than brute-force search.
- ✅ Search space becomes half every iteration.
- ✅ Works only when the search space is **ordered**.
- ✅ Used in binary search, optimization, and numerical methods.

# Newton-Raphson Method

## What is Newton-Raphson?

The **Newton-Raphson Method** is an **iterative approximation algorithm** used to find the **roots (zeros)** of a function.

A **root** is a value of `x` where:

```text
f(x) = 0
```

Instead of checking many possible answers, Newton-Raphson starts with an **initial guess** and repeatedly improves it until it reaches the root.


---

## General Polynomial

For a polynomial

```text
p(x) = anxⁿ + an-1xⁿ⁻¹ + ... + a₁x + a₀
```

Newton and Raphson showed that if `g` is an approximation of the root, then a better approximation is

```text
new_guess = g - p(g) / p'(g)
```

where

- `p(g)` → value of the function
- `p'(g)` → derivative (slope) of the function

![Newton-Raphson Graph](Pasted%20image%2020260725220204.png)

---

## Finding the Square Root

Suppose we want to find

```text
√k
```

Instead of solving directly, define

```text
p(x) = x² - k
```

The root of this equation is

```text
x² - k = 0
```

which gives

```text
x = √k
```

---

## Derivative

For

```text
p(x) = x² - k
```

the derivative is

```text
p'(x) = 2x
```

---

## Newton-Raphson Formula

Substitute into

```text
new_guess = g - p(g) / p'(g)
```

We get

```text
new_guess = g - (g² - k) / (2g)
```

This formula repeatedly improves the guess until it is very close to `√k`.

---

# Algorithm

1. Start with an initial guess.
2. Compute a better guess using

```text
g = g - (g² - k) / (2g)
```

3. Repeat until

```text
|g² - k| < epsilon
```

---

# Python Implementation

```python
epsilon = 0.01
k = 24.0

# Initial guess
guess = k / 2.0

num_guesses = 0

while abs(guess * guess - k) >= epsilon:

    num_guesses += 1

    # Newton-Raphson Formula
    guess = guess - ((guess**2 - k) / (2 * guess))

print("num_guesses =", num_guesses)
print("Square root of", k, "is about", guess)
```

---

# Understanding the Graph

The graph above shows how Newton-Raphson works.

1. Start with an **initial guess** `x₁`.
2. Move vertically to the curve `f(x)`.
3. Draw the tangent line at that point.
4. The tangent intersects the x-axis at a new point `x₂`.
5. Repeat the same process.
6. Each iteration gets **closer to the exact root**.

The circled points on the x-axis represent:

```text
Initial Guess  →  x₁
1st Iteration  →  x₂
2nd Iteration  →  x₃
3rd Iteration  →  ...
```

Eventually the guesses converge to the **exact root**.

---

# Why is Newton-Raphson Fast?

Unlike:

- Exhaustive Search → checks every possibility.
- Approximation → moves by tiny increments.
- Bisection Search → halves the search space.

Newton-Raphson uses the **slope (derivative)** of the function to jump much closer to the answer every iteration.

It usually converges in only a few iterations.

---

# Comparison of Root-Finding Algorithms

| Method | Idea | Time |
|---------|------|------|
| Exhaustive Enumeration | Check every value | Slow |
| Approximation | Small increments | Slow |
| Bisection Search | Halve the search space | Fast |
| Newton-Raphson | Use tangent line (derivative) | Fastest (usually) |

---

# Iterative Algorithms

All these algorithms follow the same pattern:

1. Make an initial guess.
2. Improve the guess.
3. Check if it is close enough.
4. Repeat until the error is less than `epsilon`.

Different algorithms differ **only in how they generate the next guess**.

- Exhaustive Enumeration
- Approximation
- Bisection Search
- Newton-Raphson
