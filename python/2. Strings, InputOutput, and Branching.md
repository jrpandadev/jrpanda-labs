## 📝 Strings in Python

### What is a String?
A **string** is a sequence of characters enclosed in quotes.

```python
str1 = "Hello World"
str2 = 'Python'
```

> [!NOTE]
> **Strings are immutable**, meaning they cannot be modified after creation.
> ```python
> s = "hello"
> s[0] = "W"   # TypeError: 'str' object does not support item assignment
> ```

---

### `len()` Function

Returns the length of a string.

```python
word = "Python"
print(len(word))   # 6
```

---

### Concatenation (`+`)

Joins two or more strings together.

```python
str1 = "Hello"
str2 = "World"

print(str1 + " " + str2)  # Hello World
```

---

### Repetition (`*`)

The `*` operator repeats a string multiple times.

```python 
print("Hi " * 3)   # Hi Hi Hi 
print("*" * 10)    # ********** 
print("abc" * 2)   # abcabc 
``` 

> [!NOTE]
> String repetition works only with an **integer**.

---

### String Indexing

Python uses **0-based indexing**.

```python
s = "Python"

print(s[0])    # P
print(s[3])    # h
print(s[-1])   # n
```

---

### String Slicing

Extracts part of a string.

**Syntax**
```python
string[start:stop:step]
```

```python
s = "Python"

print(s[0:4])   # Pyth
print(s[::2])   # Pto
print(s[::-1])  # nohtyP (reversed)
```

- `start` → Inclusive (default `0`)
- `stop` → Exclusive
- `step` → Increment (default `1`)

> [!NOTE]
> **Slicing never raises an `IndexError`**, even if indices are out of range. Python silently clips them:
> ```python
> "abc"[0:100]   # "abc" (stop clipped to length)
> "abc"[-100:2]  # "ab"  (start clipped to 0)
> ```
> This is different from **indexing**, where `"abc"[10]` raises an `IndexError`.

## 🧰 Common String Methods

```python
sentence = "   Python is fun!   "

print(sentence.upper())   # Uppercase
print(sentence.lower())   # Lowercase
print(sentence.strip())   # Remove leading & trailing whitespace
```

| Method | Description |
| :--- | :--- |
| `.upper()` | Converts string to uppercase |
| `.lower()` | Converts string to lowercase |
| `.strip()` | Removes leading & trailing spaces |
| `.replace(a, b)` | Replaces occurrences of `a` with `b` |
| `.find()` | Returns first index of substring (`-1` if not found) |
| `.count()` | Counts non-overlapping occurrences |
| `.startswith()` | Checks if string starts with prefix |
| `.endswith()` | Checks if string ends with suffix |

#### Quick Examples

```python
"hello world".replace("world", "Python")  # "hello Python"
"hello".find("ll")                         # 2
"hello".find("xyz")                        # -1
```

> [!TIP]
> `.split()` with no argument splits on **any whitespace** and removes empty strings. `.split(" ")` splits on a single space only.

## ⌨️ User Input

Python uses the `input()` function to receive input from the user.

**Syntax**
```python
variable = input(prompt)
```

The string inside `input()` is displayed to the user as a prompt. Python waits for the user to type a value and press **Enter**.

```python
name = input("Enter your name: ")
```

> [!IMPORTANT]
> `input()` **always returns a string (`str`)**, regardless of what the user types.

### Common Type Conversion Pattern

```python
age = int(input("Enter your age: "))   # Convert to int
pi = float(input("Enter pi: "))        # Convert to float
```

> [!WARNING]
> If the user enters something that can't be converted, Python raises a `ValueError`:
> ```python
> int("hello")  # ValueError
> ```

## 📐 Newton's Method (Introduction)

> [!NOTE]
> **Newton's Method** is an algorithm used to find the **roots of a polynomial** using **successive approximation**.

### Objective
Find a value `g` such that:
$$f(g, x) = g^3 - x = 0$$

For example, to find the **cube root** of `x`, we want a value `g` where $g^3 = x$.

### Algorithm Formula
Newton's Method computes a better approximation using the formula:
$$\text{next guess} = \text{guess} - \frac{f(\text{guess})}{f'(\text{guess})}$$

For $f(g, x) = g^3 - x$, the next guess becomes:
$$\text{next guess} = \text{guess} - \frac{g^3 - x}{3g^2}$$

### Algorithm Steps
1. Read the number whose cube root is to be found.
2. Read an initial guess.
3. Compute the cube of the current guess.
4. Apply Newton's Method formula.
5. Compute the next approximation.
6. Display the new guess.

### Implementation Example
```python
# Try Newton-Raphson for cube root

x = int(input("What x to find the cube root of? "))
g = int(input("What guess to start with? "))

print("Current estimate cubed =", g**3)

next_g = g - ((g**3 - x) / (3 * g**2))

print("Next guess to try =", next_g)
```

> [!IMPORTANT]
> Newton's Method improves an estimate by repeatedly computing a **better approximation** using the current guess.

## ⚖️ Assignment vs Equality

### Assignment (`=`)
Stores a value in a variable.

```python
x = 10
```
1. Right-hand side is evaluated.
2. Value is stored in memory.
3. Variable on the left is bound to that value.

> [!IMPORTANT]
> Assignment **modifies** variable bindings. It does **not** compare.

---

### Equality (`==`)
Checks whether two values or expressions are equal.

```python
5 == 5    # True
5 == 10   # False
```

> [!IMPORTANT]
> - `=` **assigns** a value (`x = 5`).
> - `==` **compares** two values for equality (`x == 5`) and returns a `bool`.

---

### Identity (`is`) vs Equality (`==`)

| Operator | Checks | Question It Answers |
| :---: | :--- | :--- |
| `==` | Whether two values are **equal** | "Do they have the same content?" |
| `is` | Whether two variables point to the **same object in memory** | "Are they the exact same object?" |

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)  # True  (same content)
print(a is b)  # False (different objects in memory)
```

> [!WARNING]
> **Common misconception**: Always use `==` for value comparison. Use `is` only to check for `None`:
> ```python
> if x is None:     # ✅ Correct
> if x == None:     # ❌ Works but not Pythonic
> ```

## 🎯 Boolean Type (`bool`) & Logical Flow

Boolean has only two possible values: `True` or `False`.

### Comparison Operators

| Operator | Meaning |
| :---: | :--- |
| `>` | Greater than |
| `>=` | Greater than or equal to |
| `<` | Less than |
| `<=` | Less than or equal to |
| `==` | Equal to |
| `!=` | Not equal to |

All comparison operators evaluate to a value of type **`bool`**.

---

## 🔀 Branching & Conditional Statements

Branching allows a program to execute different blocks of code depending on whether a condition evaluates to `True` or `False`.

### Types of Conditional Statements

- **`if`**: Executes a block if the condition is **True**.
- **`elif`** (Else If): Checks another condition if the previous one is **False**.
- **`else`**: Executes if **all previous conditions are False**.

> [!NOTE]
> - You can have multiple `if` and `elif` statements.
> - `elif` and `else` **must** follow an initial `if`.

```python
age = 18

if age > 18:
    print("Adult")
elif age == 18:
    print("Just Adult")
else:
    print("Minor")
```

---

## ⚡ Ternary Statement

A **ternary statement** is a **one-line shortcut** for an `if-else` statement.

**Syntax**
```python
value_if_true if condition else value_if_false
```

**Example**
```python
age = 20
status = "Adult" if age >= 18 else "Minor"
print(status)  # Adult
```

> [!TIP]
> Use ternary statements for simple assignments to preserve readability.

| Concept | Key Point |
