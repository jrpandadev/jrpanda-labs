# 📝 Strings in Python

## What is a String?
A **string** is a sequence of characters enclosed in quotes.

```python
str1 = "Hello World"
str2 = 'Python'
```

> [!NOTE]
> **Strings are immutable**, meaning they cannot be changed after creation.

---

## `len()` Function

Returns the length of a string.

```python
word = "Python"
print(len(word))   # 6
```

---

## Concatenation (`+`)

Joins two or more strings.

```python
str1 = "Hello"
str2 = "World"

print(str1 + " " + str2)
```

---

## Repetition (`*`) 

 The `*` operator repeats a string multiple times.

```python 
print("Hi " * 3) 
# Hi Hi Hi 
``` 
```python 
print("*" * 10) 
# ********** 
``` 
```python 
print("abc" * 2) 
# abcabc 
```

> [!NOTE]
> String repetition works only with an **integer**.


---
## String Indexing

Python uses **0-based indexing**.

```python
s = "Python"

print(s[0])    # P
print(s[3])    # h
print(s[-1])   # n
```

---

## String Slicing

Extracts part of a string.

**Syntax**
```python
string[start:stop:step]
```

```python
s = "Python"

print(s[0:4])   # Pyth
print(s[::2])   # Pto
print(s[::-1])  # nohtyP
```

- `start` → Inclusive (default `0`)
- `stop` → Exclusive
- `step` → Increment (default `1`)

---

# 🎨 String Formatting

### 1. Using `.format()`

```python
name = "Rahul"
age = 25

print("My name is {} and I am {} years old".format(name, age))
```

---

### 2. Using f-strings (Recommended)

```python
name = "Rahul"
age = 25

print(f"My name is {name} and I am {age} years old")
```

Expressions are also allowed:

```python
a = 5
b = 10

print(f"Sum = {a + b}")
```

---

## Common String Methods

```python
sentence = "   Python is fun!   "

print(sentence.upper())   # Uppercase
print(sentence.lower())   # Lowercase
print(sentence.strip())   # Remove spaces
```

| Method           | Description                       |
| ---------------- | --------------------------------- |
| `.upper()`       | Converts to uppercase             |
| `.lower()`       | Converts to lowercase             |
| `.strip()`       | Removes leading & trailing spaces |
| `.replace(a, b)` | Replaces text                     |
| `.split()`       | Splits into a list                |
| `.find()`        | Returns first index of substring  |
| `.count()`       | Counts occurrences                |
| `.startswith()`  | Checks starting text              |
| `.endswith()`    | Checks ending text                |

# User Input

Python uses the `input()` function to receive input from the user.

General syntax

```python
variable = input(prompt)
```

The string inside `input()` is displayed to the user as a prompt.

Python then waits for the user to type a value and press **Enter**.

The entered value is assigned to the variable.

Example

```python
name = input("Enter your name: ")
```

---

# Important Rule

> [!IMPORTANT]
> `input()` **always returns a string (`str`)**, regardless of what the user types.

# Newton's Method

> [!NOTE]
> **Newton's Method** is an important algorithm used to find the **roots of a polynomial** using **successive approximation**.

---

## Objective

Find a value `g` such that:

```text
f(g, x) = g³ − x = 0
```

For example, to find the **cube root** of `x`, we want a value `g` where:

```text
g³ = x
```

---

## Algorithm

Newton's Method computes a better approximation using the formula:

```text
next_guess = guess − f(guess) / f′(guess)
```

For the function:

```text
f(g, x) = g³ − x
```

the next guess becomes:

```text
next_guess = guess − (g³ − x) / (3g²)
```

Each new guess is expected to be closer to the actual cube root.

---

## Algorithm Steps

1. Read the number whose cube root is to be found.
2. Read an initial guess.
3. Compute the cube of the current guess.
4. Apply Newton's Method formula.
5. Compute the next approximation.
6. Display the new guess.

---

## Example Code

```python
# Try Newton-Raphson for cube root

x = int(input("What x to find the cube root of? "))
g = int(input("What guess to start with? "))

print("Current estimate cubed =", g**3)

next_g = g - ((g**3 - x) / (3 * g**2))

print("Next guess to try =", next_g)
```

---

## Key Idea

> [!IMPORTANT]
> Newton's Method improves an estimate by repeatedly computing a **better approximation** using the current guess.

Each iteration moves the estimate closer to the desired root.

# Assignment (`=`)

Assignment stores a value in a variable.

General syntax

```python
variable = value
```

Example

```python
x = 10
```

What happens?

1. The value on the right-hand side is evaluated.
2. The value is stored in memory.
3. The variable on the left-hand side is bound to that value.

> [!IMPORTANT]
> Assignment **changes** the value stored in a variable.
>
> It does **not** compare values.

---

# Equality (`==`)

The equality operator checks whether two values or expressions are equal.

General syntax

```python
value1 == value2
```

Example

```python
5 == 5    # True
5 == 10   # False
```

What happens?

1. Evaluates expressions on both sides.
2. Compares the two values.
3. Evaluates to a boolean value (`True` or `False`).

> [!IMPORTANT]
> - `=` **assigns** a value to a variable (`x = 5`).
> - `==` **compares** two values for equality (`x == 5`).
> - It does **not** modify variable values.

# Boolean Type (`bool`)

Boolean is a built-in data type.

It has **only two possible values**.

```python
True
```

```python
False
```

Comparison operations always produce a Boolean value.

---

# Comparison Operators

| Operator | Meaning |
|----------|---------|
| `>` | Greater than |
| `>=` | Greater than or equal to |
| `<` | Less than |
| `<=` | Less than or equal to |
| `==` | Equal to |
| `!=` | Not equal to |

All comparison operators evaluate to a value of type **`bool`**.

---

# Why Use Boolean Values?

Boolean values are used for **flow of control**.

Programs need a way to determine whether a condition is:

- `True`
- `False`

This allows the program to make decisions.

Example

```text
If something is true,
do one thing.

Otherwise,
do something else.
```

---
# Branching

Branching allows a program to execute different blocks of code depending on whether a condition evaluates to `True` or `False`.

Interesting algorithms involve making decisions, and branching provides the mechanism for those decisions.

# 🔀 Conditional Statements

Conditional statements allow a program to make decisions based on **True** or **False** conditions.

## Types of Conditional Statements

### 1. `if`
- Executes a block if the condition is **True**.

### 2. `elif` (Else If)
- Checks another condition if the previous one is **False**.
- Used for multiple conditions.

### 3. `else`
- Executes if **all previous conditions are False**.

> [!NOTE]
> - You can have multiple `if` and `elif` statements.
> - `elif` and `else` **cannot** be used without a preceding `if`.

### Example

```python
age = 18

if age > 18:
    print("Adult")
elif age == 18:
    print("Just Adult")
else:
    print("Minor")
```

---

# ⚡ Ternary Statement

A **ternary statement** is a **one-line shortcut** for an `if-else` statement.

### Syntax

```python
value_if_true if condition else value_if_false
```

### Example

```python
age = 20
status = "Adult" if age >= 18 else "Minor"
print(status)
```

> [!TIP]
> Use ternary statements only for **simple conditions**.

---

# 🔄 Match-Case Statement (Python 3.10+)

`match-case` is an alternative to long `if-elif-else` chains.

### Syntax

```python
match variable:
    case pattern1:
        # code
    case pattern2:
        # code
    case _:
        # default case
```

### Example

```python
day = 2

match day:
    case 1:
        print("Monday")
    case 2:
        print("Tuesday")
    case _:
        print("Invalid Day")
```

### Key Terms
- `match` → Variable to compare.
- `case` → Value/pattern to match.
- `_` → Wildcard (default case, like `else`).
