## 📝 Strings in Python

### What is a String?
A **string** is a sequence of characters enclosed in quotes.

```python
str1 = "Hello World"
str2 = 'Python'
```

> [!NOTE]
> **Strings are immutable**, meaning they cannot be modified after creation.
> ```python
> s = "hello"
> s[0] = "W"   # TypeError: 'str' object does not support item assignment
> ```

---

### String Operations

| Operation | Syntax | Description | Example | Result |
| :--- | :--- | :--- | :--- | :--- |
| **Length** | `len(s)` | Returns the number of characters | `len("Python")` | `6` |
| **Concatenation** | `s1 + s2` | Joins strings together | `"Hi" + " " + "Mom"` | `"Hi Mom"` |
| **Repetition** | `s * n` | Repeats string `n` times | `"Hi" * 3` | `"HiHiHi"` |
| **Membership** | `sub in s` | Checks if a substring exists in a string | `"a" in "apple"` | `True` |

> [!NOTE]
> String repetition (`*`) works only with an **integer**. `"Hi" * 3.0` raises a `TypeError`.

---

### String Indexing

Python uses **0-based indexing**.

```python
s = "Python"

print(s[0])    # P
print(s[3])    # h
print(s[-1])   # n (Negative indexing starts from the end)
```

---

### Escape Characters

| Escape | Meaning |
|--------|---------|
| `\n` | New line |
| `\t` | Tab |
| `\"` | Double quote |
| `\\` | Backslash |

---

### String Slicing

Extracts part of a string.

**Syntax**
```python
string[start:stop:step]
```

- `start` → Inclusive (default `0`)
- `stop` → Exclusive (default end of string)
- `step` → Increment (default `1`)

```python
s = "Python"

print(s[0:4])   # Pyth
print(s[::2])   # Pto
print(s[::-1])  # nohtyP (reversed)
```

> [!TIP]
> **Slicing never raises an `IndexError`**, even if indices are out of range. Python silently clips them:
> ```python
> "abc"[0:100]   # "abc" (stop clipped to length)
> "abc"[-100:2]  # "ab"  (start clipped to 0)
> ```
> This is different from **indexing**, where `"abc"[10]` crashes with an `IndexError`.

## 🎨 String Formatting

### Using f-strings (Recommended)

f-strings allow you to embed variables and expressions directly inside string literals by prefixing the string with `f`.

```python
name = "Rahul"
age = 25

print(f"My name is {name} and I am {age} years old.")
print(f"Next year I will be {age + 1}.")
```

### Using `.format()`

```python
name = "Rahul"
age = 25

print("My name is {} and I am {} years old".format(name, age))
```

## 🧰 Common String Methods

| Method | Description | Example | Result |
| :--- | :--- | :--- | :--- |
| `.upper()` | Converts string to uppercase | `"hi".upper()` | `"HI"` |
| `.lower()` | Converts string to lowercase | `"HI".lower()` | `"hi"` |
| `.strip()` | Removes leading & trailing spaces | `"  hi  ".strip()` | `"hi"` |
| `.replace(a, b)` | Replaces `a` with `b` | `"cat".replace("c", "b")` | `"bat"` |
| `.find(sub)` | Returns first index of substring (`-1` if not found) | `"hello".find("l")` | `2` |
| `.startswith(sub)` | Returns `True` if string starts with `sub` | `"Python".startswith("Py")` | `True` |
| `.endswith(sub)` | Returns `True` if string ends with `sub` | `"file.py".endswith(".py")` | `True` |
| `.count(sub)` | Returns how many times `sub` appears | `"banana".count("a")` | `3` |
| `.isdigit()` | Returns `True` if all characters are digits | `"123".isdigit()` | `True` |
| `.isalpha()` | Returns `True` if all characters are letters | `"abc".isalpha()` | `True` |
| `.split(sep)` | Splits string into a **list** of words | `"a,b".split(",")` | `["a","b"]` |

> [!TIP]
> Since strings are immutable, methods like `.upper()` do not change the original string. They return a **new** string.

> [!NOTE]
> `.isdigit()` and `.isalpha()` are extremely useful for **input validation** before casting — e.g., check `age_str.isdigit()` before calling `int(age_str)` to avoid `ValueError`.

## ⌨️ User Input

Python uses the `input()` function to receive input from the user.

**Syntax**
```python
variable = input("Prompt message: ")
```

> [!IMPORTANT]
> `input()` **always returns a string (`str`)**, regardless of what the user types. If they type `5`, it returns `"5"`.

### Common Type Conversion Pattern

If you expect a number, you must cast the result of `input()`:

```python
age = int(input("Enter your age: "))   # Convert to int
pi = float(input("Enter pi: "))        # Convert to float
```

### Customizing `print()` Output

`print()` has two optional parameters that change how output is displayed:
- **`end`** — defines what to print at the end instead of a newline (default: `"\n"`).
- **`sep`** — defines what to print between multiple values (default: `" "`).

```python
print(1, 2, 3)               # 1 2 3
print(1, 2, 3, sep="-")      # 1-2-3
print("Loading", end="...")  # Loading...(no newline)
print("Done")                # Done  (appears on the same line)
```

> [!NOTE]
> You will see `end=" "` used inside loops in Module 3 to print numbers on the same line. Now you know why!

## 🐛 Progressive Debugging: Value & Logic Errors

### 1. `ValueError` from Input Casting
If the user enters text that cannot be converted to a number, Python raises a `ValueError`.

```python
# User inputs: "twenty"
age = int(input("Enter your age: "))
# ValueError: invalid literal for int() with base 10: 'twenty'
```
*We will learn how to handle this gracefully with `try/except` in Module 8.*

### 2. Logical Errors (Order of Conditions)
When using branching (discussed next), the **order** of conditions matters. Python executes the **first** condition that evaluates to `True`.

```python
score = 85

# LOGICAL ERROR:
if score >= 50:
    print("Pass")
elif score >= 80:
    print("Distinction") # This will never run because 85 >= 50 is True!
```
**Fix:** Always put the most specific or restrictive conditions first.

## 🔀 Branching & Conditional Statements

Branching allows a program to execute different blocks of code depending on whether a condition evaluates to `True` or `False`.

### Truthiness

When a value is used in a condition (like an `if` statement), Python evaluates its "Truthiness".

**Falsy values:**
```python
0
0.0
False
None
""
[]
()
{}
set()
```
- Everything else is **Truthy**.

**Example:**
```python
x = 5

if x:
    print("A")
else:
    print("B")
```
*(Prints "A" because `5` is a truthy value)*

### `if / elif / else`

- **`if`**: Executes a block if the condition is **True**.
- **`elif`** (Else If): Checks another condition if the previous one is **False**.
- **`else`**: Executes if **all previous conditions are False**.

```python
age = 18

if age > 18:
    print("Adult")
elif age == 18:
    print("Just Adult")
else:
    print("Minor")
```

### ⚡ Pythonic Shortcut: The Ternary Operator

If you have a simple `if/else` that assigns a value, you can write it in a single line using a **conditional expression** (often called the ternary operator).

```python
# ❌ Longer Approach
if age >= 18:
    status = "Adult"
else:
    status = "Minor"

# ✅ Pythonic Approach
status = "Adult" if age >= 18 else "Minor"
```
> [!TIP]
> Use the ternary operator to make code concise, but avoid chaining them. If the logic is complex, stick to standard `if/else` for readability.

---

### 🔀 Python 3.10+: `match-case` (Structural Pattern Matching)

If you are checking the same variable against many specific values, `match-case` is much cleaner than a long chain of `if/elif`.

```python
status_code = 404

match status_code:
    case 200:
        print("Success")
    case 404:
        print("Not Found")
    case 500:
        print("Server Error")
    case _:
        print("Unknown Status")  # The underscore _ acts as the "else" or default case
```

> [!NOTE]
> The `match-case` statement is available in Python 3.10 and newer. The `_` case acts as the default if no other cases match.

## ⚡️ Chained Comparisons — A Pythonic Feature

Unlike many other languages, Python allows comparisons to be **chained** in a natural, mathematical way.

```python
age = 20

# Traditional (other languages)
if age >= 18 and age < 65:
    print("Working age")

# ✅ Pythonic (Python-specific)
if 18 <= age < 65:
    print("Working age")
```

The chained form reads exactly like a mathematical inequality and is more readable. Python evaluates it as `(18 <= age) and (age < 65)` internally.

## ⚖️ Assignment vs Equality

### Assignment (`=`)

Assignment stores a value in a variable.

**General syntax:**
```python
variable = value
```

**Example:**
```python
x = 10
```

**What happens?**
1. The value on the right-hand side is evaluated.
2. The value is stored in memory.
3. The variable on the left-hand side is bound to that value.

> [!IMPORTANT]
> Assignment **changes** the value stored in a variable.
>
> It does **not** compare values.

---

### Equality (`==`)

The equality operator checks whether two values or expressions are equal.

**General syntax:**
```python
value1 == value2
```

**Example:**
```python
5 == 5    # True
5 == 10   # False
```

**What happens?**
1. Evaluates expressions on both sides.
2. Compares the two values.
3. Evaluates to a boolean value (`True` or `False`).

> [!IMPORTANT]
> - `=` **assigns** a value to a variable (`x = 5`).
> - `==` **compares** two values for equality (`x == 5`).
> - It does **not** modify variable values.

> [!WARNING]
> Do not use `is` to check for equality. `==` checks if values are equal. `is` checks if they are the exact same object in memory.

### Question 4: Condition Ordering Bug ⭐⭐⭐ (HOTS)

Why does this code print "Warm" instead of "Hot" when `temp = 35`?
```python
temp = 35

if temp > 10:
    print("Cold")
elif temp > 20:
    print("Warm")
elif temp > 30:
    print("Hot")
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution & Fix
Because `35 > 10` is `True`, the very first `if` statement executes (printing "Cold" instead of the expected "Hot"), and all subsequent `elif` blocks are skipped entirely.

#### 🔍 Explanation
Python executes the **first** condition that evaluates to `True` and skips the rest of the branch.

**Fix:** Always put the most specific or restrictive conditions first when checking overlapping numerical ranges.
```python
if temp > 30:
    print("Hot")
elif temp > 20:
    print("Warm")
elif temp > 10:
    print("Cold")
```
</details>

A form expects the user to type a valid integer age. Write a one-line boolean check (no `try/except`) that confirms the stripped input contains only digits.

age_input = input("Enter age: ").strip()

    age = int(age_input)

<details>

#### 🔍 Explanation
`.isdigit()` returns `True` only if every character in the string is a digit (`0-9`). It returns `False` for empty strings, negative numbers (which contain `-`), and floats (which contain `.`). For production code, this guards against `ValueError` without needing `try/except`.

> For negative integers or floats, `.isdigit()` is insufficient — that is where `try/except ValueError` (Module 8) becomes the right tool.

## 🏗️ Real-World Challenge: Theme Park Ticket System

### 📌 Problem Statement
You are writing a script for a theme park ticket kiosk. 
1. Ask the user for their age.
2. If they are under 12, the ticket is $15.
3. If they are 12 to 64, the ticket is $50.
4. If they are 65 or older, the ticket is $30.
5. Print a nicely formatted message stating their age and ticket price.

### 🧠 Systematic Problem-Solving Framework

<details>
<summary><b>1. Understand & Break Down</b></summary>

- **Inputs**: Age (from `input()`, needs to be cast to `int`).
- **Outputs**: Formatted string with age and price.
- **Steps**:
  1. Prompt for age and cast to `int`.
  2. Use `if/elif/else` branching to determine the price.
  3. Use an f-string to print the final result.
</details>

<details>
<summary><b>2. Implementation (Try it yourself first!)</b></summary>

```python
# 1. Gather Input
# We use int() to cast the string from input() to an integer
age = int(input("Welcome to the park! Please enter your age: "))

# 2. Branching Logic
if age < 12:
    price = 15
elif age < 65:
    price = 50
else:
    price = 30

# 3. Output Formatting
print(f"Because you are {age} years old, your ticket costs ${price}.")
```
</details>

<details>
<summary><b>3. Edge Cases & Debugging</b></summary>

- **What if the user types "-5"?**
  - The script will evaluate `-5 < 12` as True and charge $15. We could add a check: `if age < 0: print("Invalid age")`.
- **What if the user types "twelve"?**
  - `int("twelve")` raises a `ValueError` crashing the program.
</details>

## 🔑 Key Takeaways

| Concept | Key Point |
| :--- | :--- |
| **Strings** | Immutable sequences of characters — use indexing, slicing, and methods |
| **f-strings** | Preferred formatting: `f"Hello {name}"` |
| **`input()`** | Always returns a `str` — cast with `int()` or `float()` |
| **`ValueError`** | Caused when trying to cast incompatible text (e.g., `int("abc")`) |
| **Branching** | `if/elif/else` checks conditions top-to-bottom. Put specific conditions first! |
| **Chained comparisons** | `0 < x < 10` is valid Python and equivalent to `0 < x and x < 10` |
| **Truthiness** | `""`, `0`, `None`, `[]`, `()`, `{}` are falsy — everything else is truthy |
