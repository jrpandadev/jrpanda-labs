## 🧩 Decomposition

**Decomposition** is the process of breaking a large program into **smaller, self-contained, reusable parts (modules/functions).**

### Benefits
- Makes code easier to understand.
- Keeps code organized.
- Improves readability.
- Promotes code reuse.

> [!note]
> A self-contained module should perform its task using only its inputs and basic operations.

---

## 🎭 Abstraction

**Abstraction** means focusing on **what a piece of code does**, not **how it does it**.

It hides unnecessary implementation details and exposes only the required functionality.

### Example

Without abstraction:

```python
area = 3.14 * 2.2 * 2.2
```

Using variables (more abstract and readable):

```python
pi = 3.14
r = 2.2

area = pi * r**2
```

Now it's clear that the program is calculating the **area of a circle**.

## 🧩 Functions Support Modularity

Functions help make programs **modular**, meaning they divide a large program into **small, reusable, and independent pieces**.

### Example: Bisection Square Root Function

```python
def bisection_root(x):
    epsilon = 0.01
    low = 0
    high = x
    ans = (low + high) / 2.0

    while abs(ans**2 - x) >= epsilon:

        if ans**2 < x:
            low = ans
        else:
            high = ans

        ans = (low + high) / 2.0

    return ans
```

### Calling the Function

```python
print(bisection_root(4))
print(bisection_root(123))
```

> A function can be called **multiple times** with different inputs.

## ⚙️ Functions in Python

A **function** is a named, reusable block of code designed to perform a specific action.

### Defining and Calling a Function

```python
def greet(name):
    """Docstring: Prints a greeting message."""
    print(f"Hello, {name}!")

greet("Alice")  # Calling the function
```

### Function Anatomy
1. **`def` Keyword**: Indicates a function definition.
2. **Name**: Identifier used to call the function (`greet`).
3. **Parameters**: Input variables accepted by the function (`name`).
4. **Docstring**: Documentation describing the function's contract (accessible via `.__doc__` or `help()`).
5. **Type Annotations**: Optional type hints for parameters and return values (accessible via `.__annotations__`).
6. **Body**: Statements executed when called.
7. **Return Value**: Value returned to the caller using `return`.

---

## 🔍 What Happens During a Function Call?

Example:

```python
def square(n):
    return n ** 2

print(square(5))
```

Python performs these steps:

1. Creates a **new local scope**.
2. Assigns the argument to the parameter.

```python
n = 5
```

3. Executes the function body.

```python
5 ** 2
```

4. Returns the result.

```text
25
```

5. Deletes the local scope.

---

Functions in Python are broadly divided into two categories based on whether they return a value:

1. **Fruitful Functions**: Functions that return a value using `return`.
2. **Void Functions**: Functions that perform an action (like `print()`) but do **not** explicitly return a value. 

> [!IMPORTANT]
> In Python, **void functions still return a value** — they automatically return **`None`**!

### `return` (Fruitful Functions)

- Used **only inside a function**.
- Sends a value back to the function caller.
- Immediately ends the function.
- Any code after `return` is **not executed**.

```python
def add(x, y):
    return x + y

result = add(2, 3)

print(result)
```

**Output**
```text
5
```

---

### `print()` and Void Functions

- Displays output on the screen.
- Can be used **inside or outside** functions.
- Does **not** return the printed value (it returns `None`).

```python
def greet():
    print("Hello")

result = greet()
print(result)
```

**Output**
```text
Hello
None
```

---

### Example

```python
def add(x, y):
    return x + y

def mult(x, y):
    print(x * y)

add(1, 2)
print(add(2, 3))
```

- `mult(4,5)` prints `20` but returns `None`.
- Therefore `print(mult(4,5))` prints `None`.

## 🐛 Progressive Debugging: Missing Returns & Scope

### 1. `TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'`
This error usually happens when you try to do math on the result of a function that used `print()` instead of `return`.

```python
def double(x):
    print(x * 2) # BUG! Forgot 'return'

val = double(5)
total = val + 10 # Crash! You are trying to add None + 10.
```

### 2. `UnboundLocalError: cannot access local variable`
This occurs when you try to modify a global variable inside a local function without declaring it `global`.

```python
score = 0

def increase_score():
    score += 10 # BUG! Python thinks 'score' is a new local variable.
```
**Fix**: Avoid modifying global variables inside functions. Instead, pass the value as an argument and `return` the new value.

### 3. The `nonlocal` Keyword
For **nested functions** (a function defined inside another function), use `nonlocal` to modify a variable from the enclosing (but non-global) scope.

```python
def make_counter():
    count = 0
    def increment():
        nonlocal count  # Refers to 'count' in make_counter's scope
        count += 1
        return count
    return increment

counter = make_counter()
print(counter())  # 1
print(counter())  # 2
```

## 🌐 Function Scope

Every time a function is called, Python creates a **new scope (environment/frame)**.

This scope stores:
- Parameters
- Local variables
- Intermediate calculations

When the function finishes, the scope is **destroyed**.

---

## 🌍 Environments

### Global Environment

- Created when the program starts.
- Variables defined outside functions belong here.

```python
x = 10
```

---

### Local Environment (Function Scope)

- Created whenever a function is called.
- Exists only during the function execution.

```python
def show():
    y = 20

show()
```

Here, `y` exists **only inside** `show()`.

## 🔍 Variable Scope

**Scope** determines where a variable can be accessed.

### Global Variable

Accessible throughout the program.

```python
x = 10

def display():
    print(x)

display()
```

---

### Local Variable

Accessible only inside the function.

```python
def display():
    y = 20
    print(y)

display()
```

Trying to access `y` outside the function causes an error.

```python
print(y)   # NameError
```

---

### 🕶️ Variable Shadowing

If a local variable has the same name as a global variable, the local variable "shadows" (hides) the global one inside the function.

```python

def shadowing_example():
    x = 50  # Local x (shadows global x)
    print("Inside:", x)

shadowing_example()
print("Outside:", x)
```

**Output:**
```text
Inside: 50
Outside: 10
```

# Functions: Default Parameters

Default parameters allow a function to use a **default value** if an argument is not provided.

They make functions more flexible and avoid repeating common values.

---

# Why Use Default Parameters?

Suppose we have a function to find the square root using **Bisection Search**.

Initially, `epsilon` (accuracy) is fixed inside the function.

```python
def bisection_root(x):

    epsilon = 0.01

    low = 0
    high = x

    guess = (low + high) / 2

    while abs(guess**2 - x) >= epsilon:

        if guess**2 < x:
            low = guess
        else:
            high = guess

        guess = (low + high) / 2

    return guess

print(bisection_root(123))
```

### Problem

- Accuracy is always `0.01`.
- To change it, we must edit the function.

---

# Add Another Parameter

Make `epsilon` an argument.

```python
def bisection_root(x, epsilon):

    low = 0
    high = x

    guess = (low + high) / 2

    while abs(guess**2 - x) >= epsilon:

        if guess**2 < x:
            low = guess
        else:
            high = guess

        guess = (low + high) / 2

    return guess

print(bisection_root(123, 0.01))
```

### Problem

Every function call must provide `epsilon`.

---

# Default Parameter

Provide a default value.

```python
def bisection_root(x, epsilon=0.01):

    low = 0
    high = x

    guess = (low + high) / 2

    while abs(guess**2 - x) >= epsilon:

        if guess**2 < x:
            low = guess
        else:
            high = guess

        guess = (low + high) / 2

    return guess

print(bisection_root(123))
print(bisection_root(123, 0.5))
```

Output

```text
11.09...
11.0...
```

# Rules for Default Parameters & Argument Types

## Rule 1: Default Parameter Ordering

Default parameters must come **after** non-default parameters.

✔ Correct

```python
def greet(name, message="Hello"):
    print(message, name)
```

❌ Incorrect

```python
def greet(message="Hello", name):
    pass
```

---

## 🛡️ Safe Mutable Default Parameter Pattern

Default arguments in Python are evaluated **only once when the function is defined**, not on every call. 

If you use a mutable object (like a `list` or `dict`) as a default parameter, it persists across calls:

```python
# ❌ DANGEROUS: Mutable default parameter
def append_to(item, target=[]):
    target.append(item)
    return target
```

**Recommended Fix (Default to `None`):**

```python
# ✅ SAFE: Default to None and create local object inside
def append_to(item, target=None):
    if target is None:
        target = []
    target.append(item)
    return target

print(append_to(1))  # [1]
print(append_to(2))  # [2]
```

## 🔀 Advanced Argument Specifiers: Positional-Only (`/`) & Keyword-Only (`*`)

Python allows restricting how arguments are passed using `/` and `*` in parameter lists.

### 1. Positional-Only Arguments (`/`) — Python 3.8+

Parameters to the **left** of `/` **must** be passed positionally. They cannot be specified by keyword.

```python
def format_name(first_name, last_name, /, title=None):
    full_name = f"{first_name} {last_name}"
    if title is not None:
        full_name = f"{title} {full_name}"
    return full_name

# ✅ Valid
format_name("Jane", "Doe")                 # 'Jane Doe'
format_name("John", "Doe", title="Dr.")    # 'Dr. John Doe'

# ❌ Raises TypeError: positional-only argument passed as keyword
# format_name("John", last_name="Doe", title="Dr.")
```

> Useful for math/low-level functions where parameter names don't add semantic value: `def hypotenuse(a, b, /): return (a**2 + b**2)**0.5`.

---

### 2. Keyword-Only Arguments (`*`)

Parameters to the **right** of `*` (or after `*args`) **must** be passed using keyword syntax.

```python
# 'operator' is keyword-only
def calculate(x, y, *, operator):
    if operator == "+":
        return x + y
    elif operator == "-":
        return x - y
    return None

# ✅ Valid
print(calculate(3, 4, operator="+"))  # 7

# ❌ Raises TypeError: takes 2 positional arguments but 3 were given
# calculate(3, 4, "+")
```

---

### 3. Combining `/` and `*`

You can combine positional-only (`/`), standard, and keyword-only (`*`) parameters in a single function:

```python
def function(x, y, /, z, w, *, a, b):
    print(x, y, z, w, a, b)

# x, y: Positional-Only (left of /)
# z, w: Standard (positional or keyword)
# a, b: Keyword-Only (right of *)

# ✅ Valid calls
function(1, 2, 3, 4, a="A", b="B")
function(1, 2, z=3, w=4, a="A", b="B")
```

### 📦 Unpacking Iterables into Positional Arguments (`*`)

Preceding an iterable (list, tuple, set) with `*` in a function call unpacks its elements into independent positional arguments:

```python
def function(x, y, z):
    print(f"x = {x}, y = {y}, z = {z}")

numbers = [1, 2, 3]

# Unpacks numbers list into positional arguments x=1, y=2, z=3
function(*numbers)
```

> [!TIP]
> You can combine `*` unpacking with `*args` parameters or unpack multiple iterables in a single call:
> ```python
> numbers = [1, 2, 3]
> letters = ("a", "b", "c")

> def collect_all(*args):
>     print(args)

> collect_all(*numbers, *letters)  # (1, 2, 3, 'a', 'b', 'c')
> ```

---

### 🔑 Unpacking Dictionaries into Keyword Arguments (`**`)

Preceding a dictionary with `**` in a function call unpacks its key-value pairs into keyword arguments:

```python
def function(one, two, three):
    print(f"one = {one}, two = {two}, three = {three}")

numbers = {"one": 1, "two": 2, "three": 3}

# Equivalent to function(one=1, two=2, three=3)
function(**numbers)
```

> [!TIP]
> You can also unpack multiple dictionaries in a single call:
> ```python
> dict1 = {"a": 1, "b": 2}
> dict2 = {"c": 3, "d": 4}

> def display(**kwargs):
>     print(kwargs)

> display(**dict1, **dict2)  # {'a': 1, 'b': 2, 'c': 3, 'd': 4}
> ```

## 🧠 Functions as Arguments (Higher-Order Functions)

In Python, **functions are objects**.

This means a function can:

- Be assigned to a variable.
- Be passed as an argument.
- Be returned from another function.

A function that accepts another function as an argument is called a **Higher-Order Function**.

---

### Example

```python
def apply(criteria, n):
    """
    criteria: function returning True or False
    n: integer

    Returns the number of integers from 0 to n
    that satisfy the given criteria.
    """

    count = 0

    for i in range(n + 1):

        if criteria(i):
            count += 1

    return count
```

#### Function Passed as Argument

```python
def is_even(x):
    return x % 2 == 0

print(apply(is_even, 10))
```

**Output**

```text
6
```

The even numbers are:

```text
0 2 4 6 8 10
```

---

### Why does this work?

Instead of passing a number, we pass the function itself.

```python
apply(is_even, 10)
```

Inside `apply()`, Python calls

```python
criteria(i)
```

which becomes

```python
is_even(i)
```

for every value of `i`.

## ⚡ Lambda Functions

A **lambda function** is a short, anonymous function written in a single line.

It is created using the `lambda` keyword.

Unlike normal functions, lambda functions do **not** have a name.

### Syntax
```python
lambda parameters: expression
```

| Part | Meaning |
|---|---|
| `lambda` | Keyword that starts the function |
| `parameters` | Comma-separated inputs (like a regular function) |
| `expression` | A **single expression** whose value is returned (no `return` keyword!) |

```python
# Named function
def square(x):
    return x ** 2

# Equivalent lambda
square = lambda x: x ** 2

print(square(5))  # 25

# With two parameters
add = lambda x, y: x + y
print(add(3, 4))  # 7
```

> [!NOTE]
> Lambda functions are ideal for short, throwaway functions — especially when passing them directly as arguments to higher-order functions like `apply()` or `map()`.

# Problem: Count Numbers with Square Root Close to n

## Problem Statement

Write a function

```python
count_nums_with_sqrt_close_to(n, epsilon)
```

where

- `n` is an integer greater than 2.
- `epsilon` is a positive number less than 1.

The function returns the number of integers whose square root is within `epsilon` of `n`.

---

## Solution

```python
def count_nums_with_sqrt_close_to(n, epsilon):
    """
    n: integer > 2
    epsilon: positive float < 1

    Returns the number of integers whose
    square root is within epsilon of n.
    """

    count = 0

    # Check every integer from 0 to n²
    for i in range(n * n + 1):

        # Compare sqrt(i) with n
        if abs(i ** 0.5 - n) < epsilon:
            count += 1

    return count


print(count_nums_with_sqrt_close_to(5, 0.1))
```

### Question — Closure Variable Capture 💡 (Advanced)

What does this code print?
```python
def make_adder(n):
    def add(x):
        return x + n
    return add

add5 = make_adder(5)
add10 = make_adder(10)

print(add5(3))
print(add10(3))
print(add5(add10(1)))
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
8
13
16
```

#### 🔍 Explanation
Each call to `make_adder(n)` creates a **closure** — the inner function `add` "captures" and **remembers** the value of `n` from its enclosing scope, even after `make_adder` has finished running.
- `add5` remembers `n = 5`. So `add5(3)` → `3 + 5 = 8`.
- `add10` remembers `n = 10`. So `add10(3)` → `3 + 10 = 13`.
- `add10(1)` → `1 + 10 = 11`. Then `add5(11)` → `11 + 5 = 16`.

This is the **closure** pattern (see `make_product` above). Each returned function carries its own "memory" of the enclosing variable.
</details>

### Question — Pass-by-Assignment Trap 🪤 (Advanced)

What will this code print?

```python
def add_exclamation(text):
    text += "!"
    return text

msg = "Hello"
result = add_exclamation(msg)

print(msg)
print(result)
```

```text

```

When you pass `msg` to `add_exclamation(text)`, the local parameter `text` initially points to the same string `"Hello"`. However, because strings are **immutable**, `text += "!"` creates a **brand new string** `"Hello!"` and makes the local variable `text` point to it. 
The original global variable `msg` remains completely unchanged!
</details>

# Complete Hangman Function

```python
import random
import string

def has_player_won(secret_word, letters_guessed):
    """Returns True if every letter has been guessed."""
    for letter in secret_word:
        if letter not in letters_guessed:
            return False
    return True

def get_word_progress(secret_word, letters_guessed):
    """Returns the current guessed word."""
    progress = ""

    for letter in secret_word:
        if letter in letters_guessed:
            progress += letter
        else:
            progress += "*"
    return progress


def get_available_letters(letters_guessed):
    """Returns letters that haven't been guessed."""
    available = ""
    for letter in string.ascii_lowercase:
        if letter not in letters_guessed:
            available += letter
    return available


def hangman(secret_word, with_help):
    guesses = 10
    letters_guessed = ""
    print("Welcome to Hangman!")
    print(f"I am thinking of a word that is {len(secret_word)} letters long.")

    while guesses > 0:
        print("-" * 20)
        print(f"Guesses remaining: {guesses}")
        print("Available letters:", get_available_letters(letters_guessed))
        guess = input("Please guess a letter: ").lower()

        # ---------------- HELP FEATURE ----------------

        if guess == "!" and with_help:
            if guesses < 3:
                print("Not enough guesses for help.")
                continue

            guesses -= 3
            remaining = ""
            for letter in secret_word:
                if letter not in letters_guessed:
                    remaining += letter

            if remaining != "":
                reveal = random.choice(remaining)
                letters_guessed += reveal
                print("Letter revealed:", reveal)
                print(get_word_progress(secret_word, letters_guessed))

                # Check if player won after revealing a letter

                if has_player_won(secret_word, letters_guessed):
                    unique_letters = 0
                    seen = ""

                    for letter in secret_word:
                        if letter not in seen:
                            seen += letter
                            unique_letters += 1

                    score = guesses + 4 * unique_letters + 3 * len(secret_word)

                    print("Congratulations, you won!")

                    print("Total Score:", score)

                    return
            continue

        # ---------------- INVALID INPUT ----------------

        if len(guess) != 1 or not guess.isalpha():
            print("Invalid input.")
            continue
            
        # ---------------- ALREADY GUESSED ----------------

        if guess in letters_guessed:
            print("You already guessed that letter.")
            continue
        letters_guessed += guess

        # ---------------- CORRECT GUESS ----------------

        if guess in secret_word:
            print("Good guess:", get_word_progress(secret_word, letters_guessed))

        # ---------------- INCORRECT GUESS ----------------

        else:
            if guess in "aeiou":
                guesses -= 2
            else:
                guesses -= 1


            print("Oops! That letter is not in my word.")
            print(get_word_progress(secret_word, letters_guessed))

        # ---------------- CHECK FOR WIN ----------------

        if has_player_won(secret_word, letters_guessed):
            unique_letters = 0
            seen = ""

            for letter in secret_word:
                if letter not in seen:
                    seen += letter
                    unique_letters += 1

            score = guesses + 4 * unique_letters + 3 * len(secret_word)
            print("Congratulations, you won!")
            print("Total Score:", score)
            return

    print("Sorry, you ran out of guesses.")
    print("The word was:", secret_word)

# Example Usage

secret_word = "python"
with_help = True
hangman(secret_word, with_help)
```

## 🔑 Key Takeaways

| Concept | Key Point |
| :--- | :--- |
| **Abstraction** | Hide implementation details and focus on what a function does |
| **Decomposition** | Break large problems into small, self-contained functions |
| **`return` vs `print()`** | `return` passes data back. `print()` just displays it to the screen |
| **Scope** | Variables inside a function (local) are destroyed when the function ends |
| **`nonlocal`** | Used in nested functions to modify a variable from the enclosing (non-global) scope |
| **Debugging** | `NoneType` errors usually mean you forgot to `return` a value |
| **Modules** | Use `import` to bring in external code (like `random` or `string`) |

> [!important]
>
> - Default parameters provide values when arguments are omitted.
> - Default parameters must be placed at the end of the parameter list.
> - Keyword arguments improve readability and can be passed in any order.
> - Functions are first-class objects in Python.
> - A function can return another function, enabling reusable and customizable behavior.

### Question 2: Mutable Default Arguments 🐛 (Debugging Challenge)
A developer wrote this function to append a value to a list. What happens when it's called twice without a list argument?
```python
def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item(1))
print(add_item(2))
```
<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>
#### ✅ Solution
```text
[1]
[1, 2]
```

#### 🔍 Explanation
Default arguments in Python are evaluated **once** when the function is defined, not each time the function is called! Because a list is mutable, the same list object is used across all calls. 
**Fix:**
```python
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```
</details>

### Question 3: Global vs Local Modification 🔥 (Tricky)
What will this code print?
```python
L = [1, 2, 3]

def modify_list(my_list):
    my_list.append(4)
    my_list = [5, 6]

modify_list(L)
print(L)
```
<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>
#### ✅ Solution
`[1, 2, 3, 4]`

#### 🔍 Explanation
When `L` is passed into `modify_list`, `my_list` becomes an alias for `L`.
1. `my_list.append(4)` modifies the actual list object. (L becomes `[1, 2, 3, 4]`).
2. `my_list = [5, 6]` reassigns the *local variable* `my_list` to point to a brand new list. It does **not** change what `L` points to globally!
This tests your understanding of **aliasing** vs **variable reassignment**.
</details>
