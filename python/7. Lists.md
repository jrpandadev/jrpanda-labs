## 📝 Introduction to Lists

A **list** is an ordered, **mutable** collection of items. Because lists are mutable, you can change their contents after they are created.

### Creating and Indexing

```python
my_list = [10, "Hello", 3.14, True]

print(my_list[0])   # 10
print(my_list[-1])  # True
print(my_list[1:3]) # ['Hello', 3.14]
```

### Lists are Mutable!

Unlike tuples and strings, you can modify lists in place.

```python
numbers = [1, 2, 3, 4]
numbers[0] = 10
print(numbers) # [10, 2, 3, 4]
```

## 🔄 String ↔ List Conversion

### `split()`: String to List
Splits a string into a list of substrings based on a separator (defaults to spaces).

```python
sentence = "Python is fun"
words = sentence.split()
print(words) # ['Python', 'is', 'fun']

csv = "apple,banana,cherry"
print(csv.split(",")) # ['apple', 'banana', 'cherry']
```

### `join()`: List to String
Combines a list of **strings** into a single string using a separator.

```python
letters = ['P', 'y', 't', 'h', 'o', 'n']
word = "".join(letters)
print(word) # Python

words = ["Data", "Science"]
print("_".join(words)) # Data_Science
```

## 🧰 Common List Methods

Many list methods **mutate** the list in place and return `None`.

| Method | Description | Example (`L = [2, 1, 3]`) | Resulting `L` |
| :--- | :--- | :--- | :--- |
| `append(x)` | Adds `x` to the end | `L.append(4)` | `[2, 1, 3, 4]` |
| `extend(iterable)`| Adds all items from iterable | `L.extend([5, 6])` | `[2, 1, 3, 5, 6]` |
| `insert(i, x)` | Inserts `x` at index `i` | `L.insert(0, 9)` | `[9, 2, 1, 3]` |
| `remove(x)` | Removes the *first* occurrence of `x` | `L.remove(1)` | `[2, 3]` |
| `pop([i])` | Removes and returns item at index `i` | `val = L.pop()` | `[2, 1]` (`val=3`) |
| `sort()` | Sorts the list in place | `L.sort()` | `[1, 2, 3]` |
| `reverse()` | Reverses the list in place | `L.reverse()` | `[3, 1, 2]` |

> [!WARNING]
> Do not write `L = L.sort()`. `sort()` mutates the list and returns `None`, so `L` will become `None`!

### `sorted()` vs `.sort()` — A Critical Distinction

| | `.sort()` | `sorted()` |
| :--- | :--- | :--- |
| **What it does** | Sorts the list **in place** | Returns a **new sorted list** |
| **Return value** | `None` | A new sorted list |
| **Original list** | Modified | Unchanged |
| **Works on** | Only lists | Any iterable (tuples, strings) |

```python
L = [3, 1, 4, 1, 5]

# sorted() — non-destructive, works on any iterable
new_L = sorted(L)
print(L)      # [3, 1, 4, 1, 5]  ← unchanged
print(new_L)  # [1, 1, 3, 4, 5]  ← new list

# .sort() — in-place, modifies the original
L.sort()
print(L)      # [1, 1, 3, 4, 5]  ← modified
```

> [!TIP]
> Use `sorted()` when you need to preserve the original order. Use `.sort()` for memory efficiency when you are done with the original.

## 🎭 Nested Lists

A list can contain other lists as elements, creating a **2D list** (matrix-like structure).

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Access element at row 1, col 2
print(matrix[1][2])  # 6

# Iterate over all elements
for row in matrix:
    for element in row:
        print(element, end=" ")
    print()
```

> [!WARNING]
> **Cloning nested lists**: `L[:]` only creates a **shallow copy**. Inner lists are still aliased. Use `import copy; copy.deepcopy(L)` for fully independent nested lists.

## 🎭 Aliasing vs. Cloning

Because lists are mutable objects stored in memory, variable names act as **pointers** (or references) to the list.

### The Aliasing Problem
When you assign a list to a new variable, you are **not** making a copy. You are creating an **alias** (a second name for the same object).

```python
warm = ['red', 'yellow', 'orange']
hot = warm          # 'hot' is an ALIAS for 'warm'

hot.append('pink')  # Mutating 'hot' also mutates 'warm'

print(warm) # ['red', 'yellow', 'orange', 'pink']
```

### Cloning (Making a Copy)
To create an independent copy, use **slicing** (`[:]`) or the `list()` constructor.

```python
cool = ['blue', 'green']
chill = cool[:]     # CLONE using slicing

chill.append('purple')

print(cool)  # ['blue', 'green']
print(chill) # ['blue', 'green', 'purple']
```

> [!TIP]
> `L[:]` creates a **shallow copy**. If your list contains other lists (e.g., `[[1, 2], [3, 4]]`), the inner lists are still aliased. You must use `import copy` and `copy.deepcopy(L)` to completely clone nested lists.

## 🐛 Progressive Debugging: Mutating While Iterating

> [!CAUTION]
> **Never add or remove items from a list while iterating over it directly.**

### The Infinite Loop Bug
```python
L = [1, 2, 3]

for item in L:
    L.append(item) 
    # Python checks the next item in L, which was just appended!
    # This loop will run forever until your computer runs out of memory.
```

### The Skipped Item Bug
```python
L = [2, 2, 2, 2]

for item in L:
    L.remove(item)

print(L) # [2, 2] -> Why wasn't everything removed?
```
**Explanation:** When index `0` is removed, the list shifts left. The item that was at index `1` moves to index `0`. The loop moves on to index `1`, effectively **skipping** the new item at index `0`.

### The Fix
Always iterate over a **clone** if you need to mutate the original list!
```python
L = [2, 2, 2, 2]

for item in L[:]:  # Iterate over a CLONE
    L.remove(item) # Safely mutate the ORIGINAL

print(L) # []
```

## 🛠️ Powerful Built-in Functions for Lists

### `sum()`, `min()`, `max()`
```python
scores = [88, 72, 95, 61, 80]
print(sum(scores))  # 396
print(min(scores))  # 61
print(max(scores))  # 95
print(sum(scores) / len(scores))  # 79.2  (average)
```

### `any()` and `all()`
These are Boolean short-circuit functions over an iterable.

- **`any(iterable)`** — returns `True` if **at least one** element is truthy.
- **`all(iterable)`** — returns `True` if **every** element is truthy.

```python
scores = [88, 0, 72, 95]
print(any(scores))   # True  (at least one non-zero score)
print(all(scores))   # False (the 0 is falsy)

# Practical: check if all passwords meet minimum length
passwords = ["abc", "secure123", "pw"]
print(all(len(p) >= 8 for p in passwords))  # False
print(any(len(p) >= 8 for p in passwords))  # True
```

### `map()` and `filter()`
These higher-order functions (from Module 5's lambda concept) work directly on lists.

- **`map(func, iterable)`** — applies `func` to every element. Returns an iterator.
- **`filter(func, iterable)`** — keeps only elements where `func` returns `True`. Returns an iterator.

```python
numbers = [1, 2, 3, 4, 5]

# map: square every number
squares = list(map(lambda x: x ** 2, numbers))
print(squares)  # [1, 4, 9, 16, 25]

# filter: keep only even numbers
evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # [2, 4]
```

> [!TIP]
> **List comprehension vs `map`/`filter`**: Both accomplish the same thing. List comprehensions are generally more readable and Pythonic. `map`/`filter` shine when working with pre-defined functions:
> ```python
> # Equivalent ways to square a list
> squares = [x**2 for x in numbers]        # List comprehension (preferred)
> squares = list(map(lambda x: x**2, numbers))  # map
> ```

## 🔢 Pythonic Iteration: `enumerate()`

When iterating over a list, you often need **both the index and the item**. 

Instead of the non-Pythonic approach using `range(len())`:
```python
# ❌ Non-Pythonic (C-style)
fruits = ["apple", "banana", "cherry"]
for i in range(len(fruits)):
    print(i, fruits[i])
```

Use **`enumerate()`**, which automatically gives you a tuple of `(index, item)` for each element!
```python
# ✅ Pythonic
for index, fruit in enumerate(fruits):
    print(f"Index {index}: {fruit}")
```
> [!TIP]
> `enumerate()` is a built-in function that makes your code cleaner and more readable. Always use it when you need the index during iteration!

## 🚀 List Comprehensions

A **list comprehension** is a concise, Pythonic way to create a new list by applying an expression to every element of an iterable.

**Syntax:**
```python
[expression for element in iterable if condition]
```

### 1. Simple Mapping
```python
# Traditional
squares = []
for x in range(1, 6):
    squares.append(x ** 2)

# List Comprehension
squares = [x ** 2 for x in range(1, 6)]
print(squares) # [1, 4, 9, 16, 25]
```

### 2. Mapping with Filtering
```python
# Get squares of only EVEN numbers
even_squares = [x ** 2 for x in range(1, 6) if x % 2 == 0]
print(even_squares) # [4, 16]
```

### Question 2: Object Identity vs Equality 💼 (Interview)

What is the output?
```python
A = [1, 2]
B = [1, 2]
C = A

print(A == B)
print(A is B)
print(A is C)
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
True
False
True
```

#### 🔍 Explanation
- `A == B` is `True` because their contents are equal (Equality).
- `A is B` is `False` because they are two completely separate lists in memory (Identity).
- `A is C` is `True` because `C` is an alias pointing to the exact same object in memory as `A`.

### Question 3: The Skipped Item Bug 🔥 (Tricky)

A developer wants to remove all `2`s from the list. What is the output?
```python
L = [1, 2, 2, 3]
for item in L:
    if item == 2:
        L.remove(item)
print(L)
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
[1, 2, 3]
```

#### 🔍 Explanation
When the first `2` (at index 1) is removed, the rest of the list shifts left. The second `2` moves into index 1. But the loop proceeds to index 2, completely skipping over the second `2`! 
**Fix:** Always iterate over a clone: `for item in L[:]:`.
</details>

### Question 4: The Mutable Default Argument Trap 🧠 (HOTS)

This is one of the most famous Python interview questions. What does this code print?
```python
def add_item(item, box=[]):
    box.append(item)
    return box

print(add_item("Apple"))
print(add_item("Banana"))
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
['Apple']
['Apple', 'Banana']
```

#### 🔍 Explanation
Default arguments in Python are evaluated **only once** when the function is defined, not every time the function is called! 
Because a list is mutable, the `box` list persists across function calls. `Apple` was added to the default list, and then `Banana` was added to that same default list!
**Fix:** Never use mutable default arguments. Use `box=None` and initialize the list inside the function.
</details>

### Question 5: `any()` / `all()` Reasoning 💼 (Interview)

What does this code output?
```python
data = [0, "", None, False, []]
print(any(data))
print(all(data))
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
False

```

#### 🔍 Explanation
Every element in `data` is **falsy**: `0`, `""` (empty string), `None`, `False`, and `[]` (empty list) all evaluate to `False` in a boolean context.
- `any(data)` returns `False` because **no** element is truthy.
- `all(data)` returns `False` because **not every** element is truthy.

This question tests whether you know the falsy values beyond just `False` and `0`.

### Question 6: `sorted()` vs `.sort()` Trap 🔥 (Tricky)

What does this code print?
```python
L = [3, 1, 2]
result = L.sort()
print(result)
print(L)
```

<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text

```

## 🏗️ Real-World Challenge: Shopping Cart Manager

### 📌 Problem Statement
Build the backend logic for an online shopping cart. 
1. Start with an empty list.
2. The user can type a product name to add it to the cart.
3. If they type `"remove <item>"`, remove it from the cart (if it exists).
4. If they type `"checkout"`, print the final items separated by commas and stop the program.

### 🧠 Systematic Problem-Solving Framework

<details>
<summary><b>1. Understand & Break Down</b></summary>

- **State**: A list `cart = []`.
- **Loop**: `while True` to continually prompt the user.
- **Input Parsing**: 
  - If input is `"checkout"`, `break`.
  - If input starts with `"remove "`, extract the item and use `.remove()`.
  - Otherwise, `.append()` the item.
- **Output**: Use `", ".join(cart)` to format the final receipt.
</details>

<details>
<summary><b>2. Implementation</b></summary>

```python
cart = []
print("Welcome to PythonShop! (Type 'checkout' to finish)")

while True:
    command = input("Add item (or 'remove <item>'): ").strip()
    
    if command.lower() == "checkout":
        break
        
    elif command.lower().startswith("remove "):
        # Extract the item name using slicing (everything after "remove ")
        item_to_remove = command[7:] 
        
        if item_to_remove in cart:
            cart.remove(item_to_remove)
            print(f"{item_to_remove} removed.")
        else:
            print("Item not found in cart.")
            
    else:
        cart.append(command)
        print(f"{command} added to cart.")

print("\n--- Receipt ---")
print("Items purchased:", ", ".join(cart))
```
</details>

<details>
<summary><b>3. Edge Cases & Debugging</b></summary>

- **What if the user tries to remove an item that isn't in the cart?**
  - Using `cart.remove("laptop")` when `"laptop"` is not in the list raises a `ValueError`. 
  - **Fix:** We used the membership operator `if item_to_remove in cart:` before attempting to remove it!
</details>

## 🔑 Key Takeaways

| Concept | Key Point |
| :--- | :--- |
| **Lists vs Tuples** | Lists `[]` are mutable. Tuples `()` are immutable. |
| **`split` & `join`** | `s.split()` converts string → list. `" ".join(L)` converts list → string. |
| **Methods Mutate** | `append()`, `remove()`, `sort()` change the list in place and return `None`. |
| **`sorted()` vs `.sort()`** | `sorted()` returns a new list; `.sort()` mutates in place and returns `None`. |
| **Nested Lists** | Use `matrix[row][col]` to access elements. Use `deepcopy()` to fully clone. |
| **Aliasing** | `L2 = L1` creates a pointer. Mutating `L2` mutates `L1`. |
| **Cloning** | `L2 = L1[:]` creates a shallow copy. |
| **Iteration Bug** | **Never** add/remove items from a list while iterating over it directly. Iterate over a clone `[:]`. |
| **`any()` / `all()`** | `any()` = at least one truthy. `all()` = every element truthy. |
| **`map()` / `filter()`** | Apply a function to every item / keep items matching a condition. |
