## 📦 What is a Tuple?

A **tuple** is an **ordered, immutable** collection of objects.

- Ordered → Elements have a fixed position (index).
- Immutable → Elements cannot be changed after creation.
- Can store objects of different data types.

> [!NOTE]
> Tuples are similar to lists, but unlike lists they are **immutable**. Because of this, tuples are generally **faster** than lists.

## 🔒 Tuples are Immutable

```python
t = (2, "MIT", 3)

t[1] = 4
```

**Output**

```text
TypeError
```

Elements of a tuple cannot be modified.

> [!WARNING]
> Attempting to assign to a tuple index raises a `TypeError`. If you need a mutable sequence, use a **list** instead.

## 🎯 Indexing & Slicing Practice

Given:

```python
seq = (2, 'a', 4, (1, 2))
```

| Expression | Output | Why |
| :--- | :--- | :--- |
| `len(seq)` | `4` | Four top-level elements |
| `seq[3]` | `(1, 2)` | Element at index 3 is a nested tuple |
| `seq[-1]` | `(1, 2)` | Last element (same as index 3) |
| `seq[3][0]` | `1` | First element of the nested tuple |
| `seq[4]` | `IndexError` | Index out of range |
| `seq[1]` | `'a'` | Element at index 1 |
| `seq[-2:]` | `(4, (1, 2))` | Last two elements |
| `seq[1:4:2]` | `('a', (1, 2))` | Indices 1 and 3 (step of 2) |
| `seq[:-1]` | `(2, 'a', 4)` | All except the last element |
| `seq[1:3]` | `('a', 4)` | Elements at indices 1 and 2 |

> [!TIP]
> When working with nested tuples, chain the index operators to drill into inner elements: `seq[3][0]` accesses the first item inside the tuple at position 3.

## 🔀 Swapping Variables

Tuples make swapping values very easy.

```python
x = 10
y = 20

x, y = y, x

print(x, y)
```

**Output**

```text
20 10
```

## ↩️ Returning Multiple Values

A function can return multiple values by returning a tuple.

```python
def quotient_and_remainder(x, y):

    q = x // y
    r = x % y

    return (q, r)
```

Calling the function:

```python
result = quotient_and_remainder(10, 3)

print(result)
```

**Output**

```text
(3, 1)
```

---

## 📤 Tuple Unpacking

The returned tuple can be unpacked into multiple variables.

```python
quot, rem = quotient_and_remainder(5, 2)

print(quot)
print(rem)
```

**Output**

```text
2
1
```

## 🧪 Practice Problem: Character Counter

### Problem

Write a function `char_counts(s)` that returns the number of vowels and consonants as a tuple.

```python
char_counts(s)
```

Returns:
- Number of vowels
- Number of consonants

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution

```python
def char_counts(s):
    """
    s is a string of lowercase letters.

    Returns a tuple:
    (number_of_vowels, number_of_consonants)
    """

    vowels = 0
    consonants = 0

    for ch in s:

        if ch in "aeiou":
            vowels += 1
        else:
            consonants += 1

    return (vowels, consonants)


print(char_counts("python"))
```

**Output**

```text
(1, 5)
```

#### 🔍 Explanation

The function iterates over each character. If it's a vowel (`a, e, i, o, u`), the vowel counter increments; otherwise, the consonant counter increments. Both counts are returned together as a tuple.

</details>

## 📦 Variable Number of Arguments (`*args`)

Sometimes we don't know how many arguments a function will receive.

Python provides `*args` to accept any number of positional arguments.

The arguments are stored as a **tuple**.

### Example

```python
def mean(*args):

    total = 0

    for num in args:
        total += num

    return total / len(args)


print(mean(1, 2, 3, 4, 5, 6))
```

**Output**

```text
3.5
```

> [!NOTE]
> In this example, `args` contains the tuple `(1, 2, 3, 4, 5, 6)`. The `*` operator collects all positional arguments into a single tuple.

## 🛠️ Tuple Methods

### `index(value)`

Returns the index of the **first occurrence** of a value.

```python
t = (10, 20, 30, 20)

print(t.index(20))
```

**Output**

```text
1
```

---

### `count(value)`

Returns the number of times a value appears.

```python
t = (10, 20, 30, 20)

print(t.count(20))
```

**Output**

```text
2
```

> [!NOTE]
> `index()` and `count()` are the **only two** methods available on tuples, since tuples are immutable and don't support modification operations like `append()` or `remove()`.

---

## 🔑 Key Takeaways

| Concept | Key Point |
| :--- | :--- |
| **Tuples** | Ordered, **immutable** collections — faster than lists |
| **Single-element tuple** | Requires a trailing comma: `(42,)` not `(42)` |
| **Indexing & Slicing** | Same syntax as strings/lists: `t[0]`, `t[1:3]`, `t[::-1]` |
| **Immutability** | Cannot assign to indices — `t[0] = 5` raises `TypeError` |
| **Swapping** | `x, y = y, x` uses tuple packing/unpacking under the hood |
| **Multiple returns** | Functions return tuples: `return (a, b)` |
| **Unpacking** | `q, r = func(10, 3)` — assigns each element to a variable |
| **`*args`** | Collects variable positional arguments into a tuple |
| **Methods** | Only two: `.index(val)` and `.count(val)` |
