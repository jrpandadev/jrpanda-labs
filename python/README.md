## 🚀 Quick Start

<details>
<summary><b>📌 Prerequisites & How to Use These Notes</b></summary>

### Prerequisites
- A working Python 3.10+ installation
- Basic familiarity with using a terminal or code editor
- Curiosity and willingness to experiment! 🧪

### How to Get the Most Out of These Notes
1. **Read sequentially** — modules build on each other.
2. **Try every code snippet** — copy-paste into a Python shell or file.
3. **Attempt quizzes first** — don't peek at solutions until you've tried.
4. **Use the navigation links** — headers and footers link between modules.
