# 🧩 Decomposition & Abstraction in Python

## Decomposition

**Decomposition** is the process of breaking a large program into **smaller, self-contained, reusable parts (modules/functions).**

### Benefits
- Makes code easier to understand.
- Keeps code organized.
- Improves readability.
- Promotes code reuse.

> [!NOTE]
> A self-contained module should perform its task using only its inputs and basic operations.

---

## Abstraction

**Abstraction** means focusing on **what a piece of code does**, not **how it does it**.

It hides unnecessary implementation details and exposes only the required functionality.

### Example

Without abstraction:

```python
area = 3.14 * 2.2 * 2.2
```

Using variables (more abstract and readable):

```python
pi = 3.14
r = 2.2

area = pi * r**2
```

Now it's clear that the program is calculating the **area of a circle**.

---

# Decomposition with Functions

Functions help divide a program into logical, reusable pieces.

Functions are:
- Self-contained
- Reusable
- Easy to maintain

Later, larger programs achieve decomposition using **classes**.

# Functions

A **function** is a reusable block of code that performs a specific task.

Instead of writing the same code multiple times, write it once and call it whenever needed.

---

## Defining a Function

Defining a function stores its code in memory.

```python

    print("Hello!")
```

> The function **does not run** when it is defined.

---

## Calling a Function

A function runs only when it is **called (invoked).**

```python
greet()
```

Output:

```text
Hello!
```

---

# Function Characteristics

A function usually has:

1. **Name** → Identifier of the function.
2. **Parameters** → Inputs to the function (optional).
3. **Docstring** → Description of the function (recommended).
4. **Body** → Statements executed when the function is called.
5. **Return Value** → Output returned using the `return` keyword.

---

## Function Syntax

```python
def function_name(parameters):
    """Docstring"""
    
    # Function body

    return value
```

---

## Example

```python

    return num ** 2
```

Output:


# 🧩 Functions Support Modularity

Functions help make programs **modular**, meaning they divide a large program into **small, reusable, and independent pieces**.

### Example: Bisection Square Root Function

```python
def bisection_root(x):
    epsilon = 0.01
    low = 0
    high = x
    ans = (low + high) / 2.0

    while abs(ans**2 - x) >= epsilon:

        if ans**2 < x:
            low = ans
        else:
            high = ans

        ans = (low + high) / 2.0

    return ans
```

### Calling the Function

```python
print(bisection_root(4))
print(bisection_root(123))
```

> A function can be called **multiple times** with different inputs.

# Function Scope

Every time a function is called, Python creates a **new scope (environment/frame)**.

This scope stores:
- Parameters
- Local variables
- Intermediate calculations

When the function finishes, the scope is **destroyed**.

---

# Environments

## Global Environment

- Created when the program starts.
- Variables defined outside functions belong here.

```python
x = 10
```

---

## Local Environment (Function Scope)

- Created whenever a function is called.
- Exists only during the function execution.

```python
def show():
    y = 20

show()
```

Here, `y` exists **only inside** `show()`.

---

# Variable Scope

**Scope** determines where a variable can be accessed.

## Global Variable

Accessible throughout the program.

```python
x = 10

def display():
    print(x)

display()
```

---

## Local Variable

Accessible only inside the function.

```python
def display():
    y = 20
    print(y)

display()
```

Trying to access `y` outside the function causes an error.

```python
print(y)   # NameError
```

---

# What Happens During a Function Call?

Example:

```python
def square(n):
    return n ** 2

print(square(5))
```

Python performs these steps:

1. Creates a **new local scope**.
2. Assigns the argument to the parameter.

```python
n = 5
```

3. Executes the function body.

```python
5 ** 2
```

4. Returns the result.

```text
25
```

5. Deletes the local scope.

# Return vs Print

Although both `return` and `print()` produce output, they serve different purposes.

## `return`

- Used **only inside a function**.
- Sends a value back to the function caller.
- Immediately ends the function.
- Any code after `return` is **not executed**.

```python
def add(x, y):
    return x + y

result = add(2, 3)

print(result)
```

Output

```text
5
```

---

## `print()`

- Displays output on the screen.
- Can be used **inside or outside** functions.
- Does **not** return the printed value (it returns `None`).

```python
def greet():
    print("Hello")

greet()
```

Output

```text
Hello
```

---

## Example

```python
def add(x, y):
    return x + y

def mult(x, y):
    print(x * y)

add(1, 2)
print(add(2, 3))
mult(3, 4)
print(mult(4, 5))
```

### Output

```text
5
12
20
None
```

### Explanation

- `add(1,2)` returns `3`, but it isn't printed.
- `print(add(2,3))` prints `5`.
- `mult(3,4)` prints `12`.
- `mult(4,5)` prints `20` but returns `None`.
- Therefore `print(mult(4,5))` prints `None`.

# Functions as Arguments (Higher-Order Functions)

In Python, **functions are objects**.

This means a function can:

- Be assigned to a variable.
- Be passed as an argument.
- Be returned from another function.

A function that accepts another function as an argument is called a **Higher-Order Function**.

---

## Example

```python
def apply(criteria, n):
    """
    criteria: function returning True or False
    n: integer

    Returns the number of integers from 0 to n
    that satisfy the given criteria.
    """

    count = 0

    for i in range(n + 1):

        if criteria(i):
            count += 1

    return count
```

### Function Passed as Argument

```python
def is_even(x):
    return x % 2 == 0

print(apply(is_even, 10))
```

Output

```text
6
```

The even numbers are:

```text
0 2 4 6 8 10
```

---

## Why does this work?

Instead of passing a number, we pass the function itself.

```python
apply(is_even, 10)
```

Inside `apply()`, Python calls

```python
criteria(i)
```

which becomes

```python
is_even(i)
```

for every value of `i`.

# Problem: Count Numbers with Square Root Close to n

## Problem Statement

Write a function

```python
count_nums_with_sqrt_close_to(n, epsilon)
```

where

- `n` is an integer greater than 2.
- `epsilon` is a positive number less than 1.

The function returns the number of integers whose square root is within `epsilon` of `n`.

---

## Solution

```python
def count_nums_with_sqrt_close_to(n, epsilon):
    """
    n: integer > 2
    epsilon: positive float < 1

    Returns the number of integers whose
    square root is within epsilon of n.
    """

    count = 0

    # Check every integer from 0 to n²
    for i in range(n * n + 1):

        # Compare sqrt(i) with n
        if abs(i ** 0.5 - n) < epsilon:
            count += 1

    return count


print(count_nums_with_sqrt_close_to(5, 0.1))
```

# Hangman Problem Set (MIT 6.100L)

## Objective

Implement a simplified version of the **Hangman** game by writing helper functions and the main game function.

The player has to guess the letters of a secret word before running out of guesses.

# Helper Function 1

## `has_player_won(secret_word, letters_guessed)`

### Task

Return `True` if **every letter** in `secret_word` has been guessed.

Otherwise return `False`.

### Example

```python
secret_word = "apple"
letters_guessed = ['e', 'i', 'k', 'p', 'r', 's']

print(has_player_won(secret_word, letters_guessed))
```

Output

```text
False
```

### Solution

```python
def has_player_won(secret_word, letters_guessed):
    """
    Returns True if every letter of secret_word
    has been guessed.
    """

    for letter in secret_word:

        if letter not in letters_guessed:
            return False

    return True
```

---

# Helper Function 2

## `get_word_progress(secret_word, letters_guessed)`

### Task

Return the current progress of the word.

- Guessed letters appear normally.
- Unknown letters are replaced with `*`.

### Example

```python
secret_word = "apple"
letters_guessed = ['e', 'i', 'k', 'p', 'r', 's']

print(get_word_progress(secret_word, letters_guessed))
```

Output

```text
*pp*e
```

### Solution

```python
def get_word_progress(secret_word, letters_guessed):
    """
    Returns the current guessed word.
    Unknown letters are replaced with '*'.
    """

    progress = ""

    for letter in secret_word:

        if letter in letters_guessed:
            progress += letter

        else:
            progress += "*"

    return progress
```

## `get_available_letters(letters_guessed)`

Return all lowercase English letters that have **not** been guessed.

```python
import string

def get_available_letters(letters_guessed):
```

# Complete Hangman Function

```python
import random
import string


def has_player_won(secret_word, letters_guessed):
    """Returns True if every letter has been guessed."""

    for letter in secret_word:
        if letter not in letters_guessed:
            return False

    return True


def get_word_progress(secret_word, letters_guessed):
    """Returns the current guessed word."""

    progress = ""

    for letter in secret_word:

        if letter in letters_guessed:
            progress += letter
        else:
            progress += "*"

    return progress


def get_available_letters(letters_guessed):
    """Returns letters that haven't been guessed."""

    available = ""

    for letter in string.ascii_lowercase:

        if letter not in letters_guessed:
            available += letter

    return available


def hangman(secret_word, with_help):

    guesses = 10
    letters_guessed = []

    print("Welcome to Hangman!")
    print(f"I am thinking of a word that is {len(secret_word)} letters long.")

    while guesses > 0:

        print("-" * 20)
        print(f"Guesses remaining: {guesses}")
        print("Available letters:", get_available_letters(letters_guessed))

        guess = input("Please guess a letter: ").lower()

        # Help feature
        if guess == "!" and with_help:

            if guesses < 3:
                print("Not enough guesses for help.")
                continue

            guesses -= 3

            remaining = []

            for letter in secret_word:

                if letter not in letters_guessed:
                    remaining.append(letter)

            if remaining:

                reveal = random.choice(remaining)

                letters_guessed.append(reveal)

                print("Letter revealed:", reveal)

            continue

        # Invalid input
        if len(guess) != 1 or not guess.isalpha():

            print("Invalid input.")
            continue

        # Already guessed
        if guess in letters_guessed:

            print("You already guessed that letter.")
            continue

        letters_guessed.append(guess)

        # Correct guess
        if guess in secret_word:

            print("Good guess:", get_word_progress(secret_word, letters_guessed))

        # Incorrect guess
        else:

            if guess in "aeiou":
                guesses -= 2
            else:
                guesses -= 1

            print("Oops! That letter is not in my word.")
            print(get_word_progress(secret_word, letters_guessed))

        # Check for win
        if has_player_won(secret_word, letters_guessed):

            unique_letters = len(set(secret_word))

            score = (
                guesses
                + 4 * unique_letters
                + 3 * len(secret_word)
            )

            print("Congratulations, you won!")
            print("Total Score:", score)
            return

    print("Sorry, you ran out of guesses.")
    print("The word was:", secret_word)
```

# Modules in Python

## What is a Module?

A **module** is a Python file (`.py`) that contains reusable code such as:

- Functions
- Variables
- Classes

Instead of writing the same code repeatedly, we can place it in a module and import it whenever needed.

> [!NOTE]
> Every Python file is a module.

---

# Why Use Modules?

Modules help us:

- Reuse code
- Organize programs
- Reduce duplication
- Improve readability
- Divide large programs into smaller files

---

# Creating a Module

Suppose we create a file named **math_utils.py**

```python
# math_utils.py

def add(a, b):
    return a + b


def square(x):
    return x * x


PI = 3.14159
```

---

# Importing a Module

```python

print(math_utils.square(5))
print(math_utils.PI)
```


# `__name__ == "__main__"`

When a Python file is run directly,

```python
__name__
```

is automatically set to

```python
"__main__"
```

Example

```python
def greet():
    print("Hello")


if __name__ == "__main__":
    greet()
```

If this file is imported into another program, the code inside the `if` block will **not** execute automatically.

This allows a module to be both:

- Imported into other programs.
- Run independently for testing.
