# 📖 Module 5: Decomposition, Abstraction, and Functions

## 🧩 Decomposition & Abstraction

### Decomposition

**Decomposition** is the process of breaking a complex problem or program into **smaller, self-contained, and reusable components (functions/modules)**.

#### Benefits

- Simplifies complex logic into readable chunks.
- Keeps code organized and modular.
- Enhances maintainability and debugging.
- Promotes code reusability.

> [!NOTE]
> A self-contained module should accomplish its specific task using only its parameters and defined operations.

---

### Abstraction

**Abstraction** means hiding internal implementation details and focusing on **what a piece of code does**, rather than **how it does it**.

#### Example

Without abstraction:

```python
area = 3.14 * 2.2 * 2.2
```

Using clear abstraction with variables:

```python
pi = 3.14
r = 2.2
area = pi * r**2
```

## ⚙️ Functions in Python

A **function** is a named, reusable block of code designed to perform a specific action.

### Defining a Function

```python
def greet():
    print("Hello!")
```

> Defining a function stores its instructions in memory, but **does not execute** them.

---

### Calling a Function

A function executes only when it is **called (invoked)**:

```python
greet()  # Prints: Hello!
```

---

### Function Anatomy & Characteristics

1. **Name**: Identifier used to call the function.
2. **Parameters**: Input variables accepted by the function.
3. **Docstring**: Documentation describing the function's contract.
4. **Body**: Statements executed when called.
5. **Return Value**: Value returned to the caller using `return`.

```python
def function_name(parameters):
    """Docstring explaining function purpose."""
    # Function body
    return value
```

#### Example

```python
def square(num):
    """Returns the square of a number."""
    return num ** 2

result = square(5)
print(result)  # 25
```

## 🧩 Functions Support Modularity

Functions enable modularity by encapsulating logic into reusable routines.

```python
def bisection_root(x):
    epsilon = 0.01
    low = 0
    high = x
    ans = (low + high) / 2.0

    while abs(ans**2 - x) >= epsilon:
        if ans**2 < x:
            low = ans
        else:
            high = ans
        ans = (low + high) / 2.0

    return ans

print(bisection_root(4))    # ~2.0
print(bisection_root(123))  # ~11.09
```

## 🌐 Scope & Environments

### Global Environment

- Created when program execution begins.
- Variables defined at the top level belong to the global scope.

### Local Environment (Function Scope)

- Created every time a function is called.
- Parameters and local variables exist **only** inside this frame.
- Frame is destroyed when the function finishes or returns.

```python
x = 10  # Global variable

def display():
    y = 20  # Local variable
    print(x)

display()
# print(y)  # Raises NameError: name 'y' is not defined
```

## 🔄 `return` vs `print()`

| Feature          | `return`                                       | `print()`                |
| :--------------- | :--------------------------------------------- | :----------------------- |
| **Context**      | Used inside functions                          | Can be used anywhere     |
| **Action**       | Hands a result back to caller & exits function | Displays text on console |
| **Return Value** | The specified expression                       | Returns `None`           |

```python
def add(x, y):
    return x + y

def mult(x, y):
    print(x * y)

add(1, 2)            # Returns 3 (not printed)
print(add(2, 3))     # Prints 5
mult(3, 4)           # Prints 12
print(mult(4, 5))    # Prints 20, then prints None
```

### Question 1: Multiple Returns

```python
def test(x):
    if x > 5:
        return "A"
    return "B"

print(test(10))
print(test(3))
```

## 🚀 Higher-Order Functions & Lambdas

In Python, **functions are first-class objects**. They can be passed as arguments, returned from other functions, or assigned to variables.

### Functions as Arguments

```python
def apply(criteria, n):
    """Returns count of integers from 0 to n matching criteria."""
    count = 0
    for i in range(n + 1):
        if criteria(i):
            count += 1
    return count

def is_even(x):
    return x % 2 == 0

print(apply(is_even, 10))  # 6 (0, 2, 4, 6, 8, 10)
```

---

### Lambda Functions (Anonymous Functions)

A **lambda function** is a concise, single-expression anonymous function.

**Syntax**

```python
lambda arguments: expression
```

```python
square = lambda x: x * x
print(square(5))  # 25

add = lambda a, b: a + b
print(add(2, 3))  # 5

# Passing inline lambda to higher-order function
print(apply(lambda x: x % 2 == 0, 10))  # 6
```

---

### Functions Returning Functions

```python
def do_twice(n, fn):
    return fn(fn(n))

print(do_twice(3, lambda x: x ** 2))  # (3^2)^2 = 81
```

## 🎮 Case Study: Hangman Game (MIT 6.100L)

### 📌 Game Rules & Specifications

- **Game Setup**: Player receives **10 guesses** to discover a secret word.
- **Input Rules**: Input is prompted (`input().lower()`). Valid inputs are a single letter or `!` (help feature).
- **Validation**: Invalid or repeated inputs trigger a warning with **0 guesses deducted**.
- **Guess Penalties**:
  - **Incorrect Consonant**: **-1 guess**
  - **Incorrect Vowel (`a, e, i, o, u`)**: **-2 guesses** (`y` is treated as a consonant)
- **Help Feature (`!`)**: Costs **3 guesses** to reveal 1 random unguessed letter (requires $\ge 3$ guesses left; available when `with_help=True`).
- **Scoring & Game End**:
  - **Win**: All letters guessed before running out of guesses.
    $$\text{Total Score} = (\text{guesses\_remaining} + 4 \times \text{unique\_letters}) + (3 \times \text{length\_of\_secret\_word})$$
  - **Loss**: Guesses reach $\le 0$. The secret word is revealed.

---

### 🛠️ Helper Functions

#### 1. `has_player_won(secret_word, letters_guessed)`

```python
def has_player_won(secret_word, letters_guessed):
    """Returns True if every letter in secret_word has been guessed."""
    for letter in secret_word:
        if letter not in letters_guessed:
            return False
    return True
```

#### 2. `get_word_progress(secret_word, letters_guessed)`

```python
def get_word_progress(secret_word, letters_guessed):
    """Returns progress string with guessed letters revealed and hidden letters as '*'."""
    progress = ""
    for letter in secret_word:
        if letter in letters_guessed:
            progress += letter
        else:
            progress += "*"
    return progress
```

#### 3. `get_available_letters(letters_guessed)`

```python
import string

def get_available_letters(letters_guessed):
    """Returns string of lowercase letters not yet guessed."""
    available = ""
    for letter in string.ascii_lowercase:
        if letter not in letters_guessed:
            available += letter
    return available
```

### 🎯 Full Game Implementation

```python
import random
import string


def has_player_won(secret_word, letters_guessed):
    """Returns True if every letter has been guessed."""

    for letter in secret_word:
        if letter not in letters_guessed:
            return False

    return True


def get_word_progress(secret_word, letters_guessed):
    """Returns the current guessed word."""

    progress = ""

    for letter in secret_word:
        if letter in letters_guessed:
            progress += letter
        else:
            progress += "*"

    return progress


def get_available_letters(letters_guessed):
    """Returns letters that haven't been guessed."""

    available = ""

    for letter in string.ascii_lowercase:
        if letter not in letters_guessed:
            available += letter

    return available


def hangman(secret_word, with_help):

    guesses = 10
    letters_guessed = ""

    print("Welcome to Hangman!")
    print(f"I am thinking of a word that is {len(secret_word)} letters long.")

    while guesses > 0:

        print("-" * 20)
        print(f"Guesses remaining: {guesses}")
        print("Available letters:", get_available_letters(letters_guessed))

        guess = input("Please guess a letter: ").lower()

        # ---------------- HELP FEATURE ----------------
        if guess == "!" and with_help:

            if guesses < 3:
                print("Not enough guesses for help.")
                continue

            guesses -= 3

            remaining = ""

            for letter in secret_word:
                if letter not in letters_guessed:
                    remaining += letter

            if remaining != "":

                reveal = random.choice(remaining)
                letters_guessed += reveal

                print("Letter revealed:", reveal)
                print(get_word_progress(secret_word, letters_guessed))

                # Check if player won after revealing a letter
                if has_player_won(secret_word, letters_guessed):

                    unique_letters = 0
                    seen = ""

                    for letter in secret_word:
                        if letter not in seen:
                            seen += letter
                            unique_letters += 1

                    score = guesses + 4 * unique_letters + 3 * len(secret_word)

                    print("Congratulations, you won!")
                    print("Total Score:", score)
                    return

            continue

        # ---------------- INVALID INPUT ----------------
        if len(guess) != 1 or not guess.isalpha():

            print("Invalid input.")
            continue

        # ---------------- ALREADY GUESSED ----------------
        if guess in letters_guessed:

            print("You already guessed that letter.")
            continue

        letters_guessed += guess

        # ---------------- CORRECT GUESS ----------------
        if guess in secret_word:

            print("Good guess:", get_word_progress(secret_word, letters_guessed))

        # ---------------- INCORRECT GUESS ----------------
        else:

            if guess in "aeiou":
                guesses -= 2
            else:
                guesses -= 1

            print("Oops! That letter is not in my word.")
            print(get_word_progress(secret_word, letters_guessed))

        # ---------------- CHECK FOR WIN ----------------
        if has_player_won(secret_word, letters_guessed):

            unique_letters = 0
            seen = ""

            for letter in secret_word:
                if letter not in seen:
                    seen += letter
                    unique_letters += 1

            score = guesses + 4 * unique_letters + 3 * len(secret_word)

            print("Congratulations, you won!")
            print("Total Score:", score)
            return

    print("Sorry, you ran out of guesses.")
    print("The word was:", secret_word)


# Example Usage
secret_word = "python"
with_help = True
hangman(secret_word, with_help)
```

## 📦 Modules in Python

A **module** is a `.py` file containing Python statements, functions, classes, and variables meant to be reused.

### Creating & Importing Modules

Suppose we have `math_utils.py`:

```python
# math_utils.py
def add(a, b):
    return a + b

def square(x):
    return x * x

PI = 3.14159
```

Import variations:

```python
import math_utils
print(math_utils.add(3, 4))

from math_utils import square
print(square(5))

import math_utils as mu
print(mu.PI)
```

---

### Useful Built-in Modules

| Module     | Primary Use                        | Example Functions                            |
| :--------- | :--------------------------------- | :------------------------------------------- |
| `math`     | Mathematical functions & constants | `math.sqrt()`, `math.pi`, `math.factorial()` |
| `random`   | Random number generation           | `random.randint()`, `random.choice()`        |
| `string`   | String constants                   | `string.ascii_lowercase`                     |
| `time`     | Time delays & benchmarking         | `time.sleep(2)`                              |
| `datetime` | Date & time operations             | `datetime.now()`                             |

---

### `__name__ == "__main__"`

When a Python file is run directly, Python sets `__name__ = "__main__"`. If imported, `__name__` is set to the module name.

```python
def main():
    print("Running directly!")

if __name__ == "__main__":
    main()
```

> [!NOTE]
> This pattern allows a file to serve both as a reusable module and an executable script.
