## 🤔 Why Use a Dictionary?

Suppose we want to store students' grades. We *could* use two parallel lists:

```python
names = ['Ana', 'John', 'Matt', 'Katy']
grades = ['A+', 'B', 'A', 'A']

# To find John's grade:
index = names.index('John')
print(grades[index]) # 'B'
```

This approach is messy. If we sort one list but forget to sort the other, the data is ruined. 
A much better solution is a **Dictionary**.

---

## 📖 What is a Dictionary?

A Python dictionary (`dict`) is a mutable collection that stores data as **Key-Value pairs**. 

Think of it like a real dictionary: you look up a **word (key)** to find its **definition (value)**.

```python
grades = {
    'Ana': 'A+',
    'John': 'B',
    'Matt': 'A',
    'Katy': 'A'
}
```

### 1. Dictionary Lookup
Instead of indexing with an integer (like lists), you index with a **key**.

```python
print(grades['John']) # 'B'
print(grades['Ana'])  # 'A+'
```

### 2. Adding and Modifying Entries
Dictionaries are **mutable**. You can add new pairs or update existing ones.

```python
grades['Grace'] = 'A'  # Adds a new key 'Grace'
grades['John'] = 'B+'  # Updates the existing key 'John'
print(grades)
```

### 3. Deleting Entries
Use the `del` keyword or the `.pop()` method. `.pop()` removes the key and returns its value.

```python
grades['Ana'] = 'A+'
del grades['Ana']

# Safely remove and get the value (returns None if not found)
johns_grade = grades.pop('John', None) 
```

### 4. Merging Dictionaries

**Method 1: `.update()`** — adds/overwrites keys from another dict **in place**.
```python
defaults = {"theme": "dark", "lang": "en"}
user_prefs = {"lang": "fr", "font": "mono"}

defaults.update(user_prefs)  # user_prefs overrides defaults
print(defaults)  # {'theme': 'dark', 'lang': 'fr', 'font': 'mono'}
```

**Method 2: `|` operator (Python 3.9+)** — creates a **new merged dict** without modifying the originals.
```python
merged = defaults | user_prefs  # Right side wins on key conflicts
print(merged)
```

> [!NOTE]
> Use `.update()` when you want to modify an existing dict. Use `|` when you need a new merged dict without touching the originals.

## 🔑 Key and Value Rules

### Values can be *anything*
Values in a dictionary can be integers, strings, lists, or even other dictionaries!
```python
student = {
    "name": "Jyoti",
    "age": 20,
    "scores": [80, 90, 85] # Value is a list
}
```

### Keys must be *Immutable (Hashable)*
Keys are used to quickly find data. Therefore, keys **cannot change**.
- **Valid Keys:** `int`, `float`, `str`, `bool`, `tuple`
- **Invalid Keys:** `list`, `dict` (Because they are mutable!)

```python
# INVALID: A list cannot be a key!
# d = { [1, 2]: "numbers" } # TypeError: unhashable type: 'list'

# VALID: A tuple can be a key!
d = { (1, 2): "coordinates" }
```

## 🐛 Progressive Debugging: `KeyError`

If you try to look up a key that doesn't exist, Python crashes with a `KeyError`.

```python
grades = {'Ana': 'A+'}
# print(grades['Bob']) # Crash! KeyError: 'Bob'
```

### Fix 1: The `in` operator
You can check if a key exists before looking it up.

```python
if 'Bob' in grades:
    print(grades['Bob'])
else:
    print("Bob is not in the system.")
```
> [!NOTE]
> `if 'A+' in grades:` is **False**. The `in` operator only searches the **keys**, not the values!

### Fix 2: The `.get()` method (Recommended)
`.get(key, default)` attempts to fetch the value for a key. If the key doesn't exist, it returns the default value instead of crashing.

```python
# Returns "Not Found" instead of crashing
score = grades.get('Bob', 'Not Found') 
print(score) 
```

## 📦 Variable Keyword Arguments (`**kwargs`)

Just like `*args` collects extra positional arguments into a **tuple**, `**kwargs` collects extra *keyword* arguments into a **dictionary**.

```python
def print_user_profile(username, **kwargs):
    print(f"User: {username}")
    # kwargs is a dictionary of any extra named arguments passed
    for key, value in kwargs.items():
        print(f"- {key}: {value}")

print_user_profile("admin", role="Manager", active=True, location="NY")
```

**Output**
```text
User: admin
- role: Manager
- active: True
- location: NY
```

## 👥 Dictionary Aliasing and Copying

Dictionaries are mutable objects, so **aliasing rules apply** (just like lists).

### Aliasing
Using `=` does **not** create a new dictionary; it creates an alias to the same dictionary in memory.

```python
d1 = {'a': 1, 'b': 2}
d2 = d1  # d2 is an alias of d1

d2['a'] = 100
print(d1)  # {'a': 100, 'b': 2}
```
Changing `d2` also changes `d1`.

### Copying
Use `.copy()` to create a separate (shallow) copy at the top level.

```python
d1 = {'a': 1, 'b': 2}
d2 = d1.copy()

d2['a'] = 100
print(d1)  # {'a': 1, 'b': 2}
print(d2)  # {'a': 100, 'b': 2}
```

## 🏗️ Nested Dictionaries

Dictionary values can themselves be dictionaries, allowing you to represent **hierarchical or structured data**.

```python
students = {
    "Alice": {"age": 20, "grade": "A"},
    "Bob":   {"age": 22, "grade": "B"},
}

# Access nested value
print(students["Alice"]["grade"])  # A

# Add a new nested key
students["Alice"]["major"] = "CS"
```

> [!TIP]
> Use `dict.get()` at each level to avoid `KeyError` when traversing deep structures:
> ```python
> grade = students.get("Charlie", {}).get("grade", "Not enrolled")
> ```

## 💡 Dictionary Comprehensions

Just as **list comprehensions** create lists concisely, **dictionary comprehensions** create dictionaries with a concise, readable syntax.

**Syntax:** `{key_expr: value_expr for item in iterable if condition}`

```python
# Square each number as a key-value pair
squares = {x: x**2 for x in range(1, 6)}
print(squares)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Invert a dictionary (swap keys and values)
grades = {'Ana': 'A', 'Bob': 'B', 'Cat': 'A'}
inverted = {v: k for k, v in grades.items()}
print(inverted)  # {'A': 'Cat', 'B': 'Bob'}  ← Note: 'Ana' was overwritten by 'Cat'!

# Filter: keep only students who passed
passed = {k: v for k, v in grades.items() if v != 'F'}
```

> [!WARNING]
> When inverting a dict, if multiple keys share the same value, **only the last one survives** because keys must be unique.

## 🔄 Iterating Over Dictionaries

Dictionaries provide three methods to extract their contents for iteration:

### 1. `.keys()` (Default)
Returns all the keys.
```python
for student in grades.keys():
    print("Student:", student)

# Note: "for student in grades:" does exactly the same thing!
```

### 2. `.values()`
Returns all the values.
```python
for grade in grades.values():
    print("Grade:", grade)
```

### 3. `.items()` (Most Useful!)
Returns both the key and the value as a tuple.
```python
for student, grade in grades.items():
    print(f"{student} got an {grade}")
```

## 🏋️ Practice Problems

### Practice 1: `find_grades()`
```python
def find_grades(grades, students):
    """
    grades is a dict mapping student names (str) to grades (str)
    students is a list of student names
    Returns a list containing the grades for students in the same order.
    """
    result = []
    for student in students:
        result.append(grades[student])
    return result

d = {'Ana': 'B', 'Matt': 'C', 'John': 'B', 'Katy': 'A'}
print(find_grades(d, ['Matt', 'Katy'])) # ['C', 'A']
```

### Practice 2: `find_in_L()`
Search across a list of multiple dictionaries:
```python
def find_in_L(Ld, k):
    """
    Ld is a list of dicts, k is an int
    Returns True if k is a key in any dict in Ld.
    """
    for d in Ld:
        if k in d:
            return True
    return False

d1, d2, d3 = {1: 2, 3: 4}, {2: 4, 4: 6}, {1: 1, 5: 25}
print(find_in_L([d1, d2, d3], 2)) # True
```

### Practice 3: `count_matches()`
```python
def count_matches(d):
    """
    d is a dict
    Returns how many entries have the key equal to its value.
    """
    count = 0
    for key, value in d.items():
        if key == value:
            count += 1
    return count

d = {1: 2, 'a': 'a', 5: 5}
print(count_matches(d)) # 2
```

## 🧪 Self-Check Questions & Quizzes

### Question 1: The Duplicate Key Trap 🔥 (Edge Case)

What does this code output?
```python
votes = {"Alice": 5, "Bob": 3, "Alice": 8}
print(len(votes))
print(votes["Alice"])
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
2
8
```

#### 🔍 Explanation
Dictionary keys must be **unique**. If you initialize a dictionary with duplicate keys, Python simply processes them from left to right. The first `"Alice": 5` is created, and then `"Alice": 8` immediately overwrites the value for `"Alice"`. The dictionary only contains 2 items.
</details>

---

### Question 2: The Iteration Unpacking Bug 🐛 (Debugging)

This code crashes. Why?
```python
grades = {'Ana': 'A', 'John': 'B'}
for student, grade in grades:
    print(student, grade)
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
It crashes with a `ValueError: too many values to unpack (expected 2)`.

#### 🔍 Explanation
When you iterate over a dictionary directly (`for x in grades`), Python only yields the **keys** (`'Ana'`, `'John'`). It does not yield key-value tuples. Trying to unpack the string `'Ana'` into two variables (`student, grade`) causes a crash.
**Fix:** Always use `.items()` when you want both!
`for student, grade in grades.items():`
</details>

### Question 3: Mutable Tuple Keys 🧠 (HOTS)

Can you use a tuple as a dictionary key? What if you use `t = (1, 2, [3, 4])`?

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
You can use a tuple as a key **only if** all of its elements are strictly immutable. 
Because `t = (1, 2, [3, 4])` contains a mutable list, the tuple itself becomes unhashable and **cannot** be used as a key! Attempting to do so will raise a `TypeError: unhashable type: 'list'`.
</details>

### Question 4: Dictionary Comprehension — Inversion 🔥 (Tricky)

What does `inverted` contain after this code runs? Is the result always predictable?
```python
grades = {'Ana': 'A', 'Bob': 'B', 'Cat': 'A'}
inverted = {v: k for k, v in grades.items()}
print(inverted)
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
{'A': 'Cat', 'B': 'Bob'}
```

#### 🔍 Explanation
`'Ana'` and `'Cat'` both map to `'A'`. When the comprehension processes `'Cat': 'A'`, it overwrites the earlier `'Ana': 'A'` because **dictionary keys must be unique**. The last write wins.

In Python 3.7+, dictionaries maintain **insertion order**, so the result is deterministic. However, the semantic information ("Ana has an A") is silently lost — a real danger when inverting non-injective (non-one-to-one) mappings.
</details>

### Question 5: `setdefault()` vs `.get()` vs `if in` 💼 (Interview)

Three developers write different approaches to count word frequencies. Which is correct, and which is most Pythonic?

```python
text = "the cat sat on the mat"
words = text.split()

# Approach A
freq_a = {}
for w in words:
    if w not in freq_a:
        freq_a[w] = 0
    freq_a[w] += 1

# Approach B
freq_b = {}
for w in words:
    freq_b[w] = freq_b.get(w, 0) + 1

# Approach C  
freq_c = {}
for w in words:
    freq_c.setdefault(w, 0)
    freq_c[w] += 1
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
All three produce identical results: `{'the': 2, 'cat': 1, 'sat': 1, 'on': 1, 'mat': 1}`.

#### 🔍 Explanation
- **Approach A**: Explicit `if in` check. Correct but verbose.
- **Approach B**: `dict.get(key, default)` — cleanest and most Pythonic. Preferred in interviews.
- **Approach C**: `setdefault(key, default)` initialises the key if absent. Correct but two-line.

In production Python, the most idiomatic tool is `collections.Counter(words)` — but that is from an external module and outside this curriculum.
</details>

### Question 5.1: Dictionary Mutation During Iteration 🔥 (Tricky)

This code raises a `RuntimeError`. Why?
```python
grades = {'Ana': 'A', 'Bob': 'F', 'Cat': 'B', 'Dan': 'F'}

for student in grades:
    if grades[student] == 'F':
        del grades[student]
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
`RuntimeError: dictionary changed size during iteration`

#### 🔍 Explanation
Just like mutating a **list** during iteration causes bugs, mutating a **dictionary** (adding or removing keys) during a `for` loop raises a `RuntimeError` immediately. Python detects the size change mid-loop and crashes to protect you from unpredictable behavior.

**Fix:** Iterate over a **copy** of the keys:
```python
for student in list(grades.keys()):  # Iterate over a snapshot of the keys
    if grades[student] == 'F':
        del grades[student]

print(grades)  # {'Ana': 'A', 'Cat': 'B'}
```
</details>

## 🏗️ Real-World Challenge: Word Frequency Counter

### 📌 Problem Statement
You are building an analytics tool for a blog. Given a long string of text, you need to count **how many times each word appears**.
You must use a dictionary where the **keys** are the words, and the **values** are the counts.

### 🧠 Systematic Problem-Solving Framework

<details>
<summary><b>1. Understand & Break Down</b></summary>

- **Input:** A string of text.
- **Goal:** A dictionary like `{'the': 2, 'cat': 1}`.
- **Steps:**
  1. Convert the string to lowercase so "The" and "the" are counted together.
  2. Split the string into a list of words using `.split()`.
  3. Create an empty dictionary `counts = {}`.
  4. Iterate through the words list.
  5. If the word is already in the dictionary, increment its value by 1.
  6. If the word is NOT in the dictionary, add it with a value of 1.
</details>

<details>
<summary><b>2. Implementation</b></summary>

```python
def count_word_frequencies(text):
    text = text.lower()
    words = text.split()
    
    counts = {}
    
    for word in words:
        if word in counts:
            counts[word] += 1
        else:
            counts[word] = 1
            
    return counts

# Test the function
blog_post = "The cat and the dog chased the cat"
print(count_word_frequencies(blog_post))
```

**Output:**
```text
{'the': 3, 'cat': 2, 'and': 1, 'dog': 1, 'chased': 1}
```
</details>

<details>
<summary><b>3. Refactoring with `.get()`</b></summary>

We can make our loop much cleaner using the `.get()` method!
Instead of the `if/else` block, we can say: 
*Fetch the current count of the word. If it doesn't exist, default to 0. Then add 1.*

```python
def count_word_frequencies_clean(text):
    words = text.lower().split()
    counts = {}
    
    for word in words:
        counts[word] = counts.get(word, 0) + 1
            
    return counts
```
</details>

### 🧠 Extension 1: Average of All Quiz Scores
Given a nested dictionary, compute the average of a specific field (e.g., `'mq'` for microquizzes):
```python
def get_average(data, what):
    all_data = []
    for stud in data.keys():
        # Notice we use + to concatenate lists, not .append()! 
        # .append() would create a nested list [[10], [8], [3]]
        all_data = all_data + data[stud][what]
    return sum(all_data) / len(all_data)

my_d = {
    'Ana': {'mq': [10], 'ps': [10, 10]},
    'Bob': {'ps': [7, 8], 'mq': [8]},
    'Eric': {'mq': [3], 'ps': [0]}
}
print(get_average(my_d, 'mq')) # 7.0
```

### 🧠 Extension 2: Finding the Most Frequent Word
```python
def find_frequent_word(word_dict):
    words = []
    highest = max(word_dict.values())
    
    for key, value in word_dict.items():
        if value == highest:
            words.append(key)
            
    return (words, highest)

word_dict = {'rah': 2, 'ah': 3, 'rom': 1, 'mah': 3, 'ro': 1}
print(find_frequent_word(word_dict)) # (['ah', 'mah'], 3)
```

### 🧠 Extension 3: Words Occurring More Than `x` Times
By repeatedly finding the max and then deleting it, we can extract words sorted by frequency:
```python
def occurs_often(word_dict, x):
    freq_list = []
    word_freq_tuple = find_frequent_word(word_dict)

    while word_freq_tuple[1] > x:
        freq_list.append(word_freq_tuple)
        for word in word_freq_tuple[0]:
            del(word_dict[word]) # Mutate the dictionary!
            
        if len(word_dict) == 0:
            break
            
        word_freq_tuple = find_frequent_word(word_dict)
        
    return freq_list

word_dict = {'rah': 2, 'ah': 3, 'rom': 1, 'mah': 3, 'ro': 1}
print(occurs_often(word_dict, 1)) 
# [(['ah', 'mah'], 3), (['rah'], 2)]
```

## 🧠 Core Mental Model & Comparisons

### List vs Dictionary
| List | Dictionary |
|---|---|
| Ordered sequence | Key-value mapping |
| Access using integer index | Access using key |
| Index is an integer | Key can be a hashable object |
| Elements have positions | Entries are identified by keys |
| Useful for sequential data | Useful for relationships/mappings |
| Example: `L[2]` | Example: `d["name"]` |
| Values can be any type | Values can be any type |
| Supports duplicate values | Keys must be unique |

> **Big Idea:** Use a **list** when you care about an ordered sequence of elements. Use a **dictionary** when you want to map one object (the key) directly to another object (the value).

## 🔑 Key Takeaways

| Concept | Key Point |
| :--- | :--- |
| **Dictionary `dict`** | Mutable collection of `key: value` pairs. |
| **Keys** | Must be unique and **immutable** (strings, ints, tuples). |
| **Values** | Can be **any** data type (including lists and dicts). |
| **Lookup** | `dict[key]` fetches the value. Raises `KeyError` if missing. |
| **`.get(key, default)`**| Safe lookup. Returns `default` if the key is missing. |
| **`.update(other)`** | Merges `other` into the dict in place. Existing keys are overwritten. |
| **`d1 \| d2`** | Creates a **new** merged dict (Python 3.9+). Right side wins on conflicts. |
| **Nested Dicts** | Values can be dicts. Access with chained keys: `d["a"]["b"]`. |
| **Dict Comprehension** | `{k: v for k, v in items}` — mirrors list comprehension syntax. |
| **Iteration** | Use `.items()` in a `for key, value in dict.items():` loop. |
