## 🤔 Why Use a Dictionary?

Suppose we want to store students' grades. We *could* use two parallel lists:

```python
names = ['Ana', 'John', 'Matt', 'Katy']
grades = ['A+', 'B', 'A', 'A']

# To find John's grade:
index = names.index('John')
print(grades[index]) # 'B'
```

This approach is messy. If we sort one list but forget to sort the other, the data is ruined. 
A much better solution is a **Dictionary**.

---

## 📖 What is a Dictionary?

A Python dictionary (`dict`) is a mutable collection that stores data as **Key-Value pairs**. 

Think of it like a real dictionary: you look up a **word (key)** to find its **definition (value)**.

```python
grades = {
    'Ana': 'A+',
    'John': 'B',
    'Matt': 'A',
    'Katy': 'A'
}
```

### 1. Dictionary Lookup
Instead of indexing with an integer (like lists), you index with a **key**.

```python
print(grades['John']) # 'B'
print(grades['Ana'])  # 'A+'
```

### 2. Adding and Modifying Entries
Dictionaries are **mutable**. You can add new pairs or update existing ones.

```python
grades['Grace'] = 'A'  # Adds a new key 'Grace'
grades['John'] = 'B+'  # Updates the existing key 'John'
print(grades)
```

### 3. Deleting Entries
Use the `del` keyword.

```python
del grades['Ana']
```

## 🔑 Key and Value Rules

### Values can be *anything*
Values in a dictionary can be integers, strings, lists, or even other dictionaries!
```python
student = {
    "name": "Jyoti",
    "age": 20,
    "scores": [80, 90, 85] # Value is a list
}
```

### Keys must be *Immutable (Hashable)*
Keys are used to quickly find data. Therefore, keys **cannot change**.
- **Valid Keys:** `int`, `float`, `str`, `bool`, `tuple`
- **Invalid Keys:** `list`, `dict` (Because they are mutable!)

```python
# INVALID: A list cannot be a key!
# d = { [1, 2]: "numbers" } # TypeError: unhashable type: 'list'

# VALID: A tuple can be a key!
d = { (1, 2): "coordinates" }
```

## 🐛 Progressive Debugging: `KeyError`

If you try to look up a key that doesn't exist, Python crashes with a `KeyError`.

```python
grades = {'Ana': 'A+'}
# print(grades['Bob']) # Crash! KeyError: 'Bob'
```

### Fix 1: The `in` operator
You can check if a key exists before looking it up.

```python
if 'Bob' in grades:
    print(grades['Bob'])
else:
    print("Bob is not in the system.")
```
> [!NOTE]
> `if 'A+' in grades:` is **False**. The `in` operator only searches the **keys**, not the values!

### Fix 2: The `.get()` method (Recommended)
`.get(key, default)` attempts to fetch the value for a key. If the key doesn't exist, it returns the default value instead of crashing.

```python
# Returns "Not Found" instead of crashing
score = grades.get('Bob', 'Not Found') 
print(score) 
```

## 🔄 Iterating Over Dictionaries

Dictionaries provide three methods to extract their contents for iteration:

### 1. `.keys()` (Default)
Returns all the keys.
```python
for student in grades.keys():
    print("Student:", student)

# Note: "for student in grades:" does exactly the same thing!
```

### 2. `.values()`
Returns all the values.
```python
for grade in grades.values():
    print("Grade:", grade)
```

### 3. `.items()` (Most Useful!)
Returns both the key and the value as a tuple.
```python
for student, grade in grades.items():
    print(f"{student} got an {grade}")
```

## 🧪 Self-Check Questions & Quizzes

### Question 1: Dictionary Aliasing ⭐⭐

```python
d1 = {'a': 1, 'b': 2}
d2 = d1
d2['c'] = 3
print(d1)
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
{'a': 1, 'b': 2, 'c': 3}
```

#### 🔍 Explanation
Just like lists, dictionaries are mutable objects. `d2 = d1` creates an **alias**, not a copy. Modifying `d2` also modifies `d1`.
</details>

---

### Question 2: Tuple Keys ⭐⭐⭐ (HOTS)

Can you use a tuple as a dictionary key? What about `t = (1, 2, [3, 4])`?

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
You can use a tuple as a key **only if** all of its elements are immutable. 
Because `t = (1, 2, [3, 4])` contains a mutable list, the tuple itself becomes unhashable and **cannot** be used as a key!
</details>

## 🏗️ Real-World Challenge: Word Frequency Counter

### 📌 Problem Statement
You are building an analytics tool for a blog. Given a long string of text, you need to count **how many times each word appears**.
You must use a dictionary where the **keys** are the words, and the **values** are the counts.

### 🧠 Systematic Problem-Solving Framework

<details>
<summary><b>1. Understand & Break Down</b></summary>

- **Input:** A string of text.
- **Goal:** A dictionary like `{'the': 2, 'cat': 1}`.
- **Steps:**
  1. Convert the string to lowercase so "The" and "the" are counted together.
  2. Split the string into a list of words using `.split()`.
  3. Create an empty dictionary `counts = {}`.
  4. Iterate through the words list.
  5. If the word is already in the dictionary, increment its value by 1.
  6. If the word is NOT in the dictionary, add it with a value of 1.
</details>

<details>
<summary><b>2. Implementation</b></summary>

```python
def count_word_frequencies(text):
    text = text.lower()
    words = text.split()
    
    counts = {}
    
    for word in words:
        if word in counts:
            counts[word] += 1
        else:
            counts[word] = 1
            
    return counts

# Test the function
blog_post = "The cat and the dog chased the cat"
print(count_word_frequencies(blog_post))
```

**Output:**
```text
{'the': 3, 'cat': 2, 'and': 1, 'dog': 1, 'chased': 1}
```
</details>

<details>
<summary><b>3. Refactoring with `.get()`</b></summary>

We can make our loop much cleaner using the `.get()` method!
Instead of the `if/else` block, we can say: 
*Fetch the current count of the word. If it doesn't exist, default to 0. Then add 1.*

```python
def count_word_frequencies_clean(text):
    words = text.lower().split()
    counts = {}
    
    for word in words:
        counts[word] = counts.get(word, 0) + 1
            
    return counts
```
</details>

## 🔑 Key Takeaways

| Concept | Key Point |
| :--- | :--- |
| **Dictionary `dict`** | Mutable collection of `key: value` pairs. |
| **Keys** | Must be unique and **immutable** (strings, ints, tuples). |
| **Values** | Can be **any** data type (including lists and dicts). |
| **Lookup** | `dict[key]` fetches the value. Raises `KeyError` if missing. |
| **`.get(key, default)`**| Safe lookup. Returns `default` if the key is missing. |
| **Iteration** | Use `.items()` in a `for key, value in dict.items():` loop. |
