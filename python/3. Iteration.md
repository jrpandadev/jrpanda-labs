## 🔁 Loops in Python

A **loop** executes a block of code **repeatedly** based on a condition or over a sequence.

### 1. `while` Loop

Repeats **while a condition evaluates to `True`**.

**Syntax**
```python
while condition:
    # code block
```

**Example**
```python
i = 1
while i <= 3:
    print(i)
    i += 1
```

> [!WARNING]
> If the condition never becomes `False`, it creates an **infinite loop**.
> ```python
> while True:
>     # Infinite loop
> ```

## ⏳ Challenge: Countdown Timer

### Problem Statement
Create a program that simulates a countdown timer.

### Requirements
- Prompt the user to enter a starting time in **seconds**.
- Use a **`while` loop** with a counter variable.
- Inside the loop:
  - Print the remaining time.
  - Decrement the counter by **1** (simulating one second passing).
- Once the counter reaches **0**, print `Time's up!`.
- *(Note: `time.sleep(1)` may not be available in all environments, so include it only as a comment).*

### Solution
```python
# Countdown Timer

# Prompt the user to enter the starting time in seconds
seconds = int(input("Enter the countdown time (in seconds): "))

# Continue the countdown until it reaches 0
while seconds > 0:
    print(seconds)

    # Simulate a 1-second delay
    # time.sleep(1)

    # Decrement the counter
    seconds -= 1

# Countdown finished
print("Time's up!")
```

## 🛑 Loop Control Statements

### `break`
Stops the loop **immediately** and jumps to the code following the loop.

```python
for i in range(5):
    if i == 3:
        break
    print(i)  # Prints 0, 1, 2
```

---

### `continue`
Skips the **rest of the current iteration** and jumps to the next evaluation step.

```python
for i in range(5):
    if i == 2:
        continue
    print(i)  # Prints 0, 1, 3, 4
```

## 🔁 2. `for` Loop

Used to iterate over a **sequence** (such as a string or `range()`).

**Syntax**
```python
for item in sequence:
    # code block
```

**Example**
```python
for ch in "Python":
    print(ch)
```

> [!NOTE]
> **`in`** is a **membership operator** used to iterate over or check membership in a sequence.

## 🔢 `range()` Function

Generates an arithmetic sequence of numbers (commonly used with `for` loops).

**Syntax**
```python
range(start, stop, step)
```

### Parameters
- `start` *(default = 0)* → Starting number (inclusive)
- `stop` → Ending number (**exclusive**)
- `step` *(default = 1)* → Increment value

**Example**
```python
for i in range(1, 6, 2):
    print(i)
```

**Output**
```text
1
3
5
```

## 🧪 Self-Check Questions & Quizzes

### Question 1: `for...else` Execution ⭐⭐

```python
for i in range(3):
    print(i)
else:
    print("Finished")
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
0
1
2
Finished
```

#### 🔍 Explanation
The `else` block connected to a loop executes **only if the loop finishes normally** without encountering a `break`. Since no `break` occurred, `"Finished"` is printed.
</details>

---

### Question 2: `for...else` with `break` ⭐⭐⭐

```python
for i in range(5):
    if i == 2:
        break
else:
    print("Finished")
print("Outside")
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
Outside
```

#### 🔍 Explanation
When `i == 2`, `break` terminates the loop immediately. Because a `break` occurred, the `else` block is **skipped**, and execution continues at `print("Outside")`.

> [!NOTE]
> **Loop Else Rule**: The `else` block executes **only when no `break` occurs**.
</details>

## 🏠 Challenge: Dream House Savings – Part A

### Objective
Determine the number of **months** required to save enough money for the **down payment** on a dream house. The down payment is **25% of the total cost** of the house.

### User Inputs
Prompt the user for inputs in this order (cast to `float`):
1. `yearly_salary`
2. `portion_saved`
3. `cost_of_dream_home`

### Solution
```python
# User inputs
yearly_salary = float(input("Enter your yearly salary: "))
portion_saved = float(input("Enter the portion of salary to save (decimal): "))
cost_of_dream_home = float(input("Enter the cost of your dream home: "))

# Constants
portion_down_payment = 0.25
annual_return = 0.04

# Calculations
monthly_salary = yearly_salary / 12
current_savings = 0
months = 0
down_payment = portion_down_payment * cost_of_dream_home

# Savings loop
while current_savings < down_payment:
    current_savings += current_savings * (annual_return / 12)
    current_savings += monthly_salary * portion_saved
    months += 1

print("Number of months:", months)
```

## 📈 Challenge: Dream House Savings – Part B

### Objective
Calculate the number of **months** required to save enough money for the down payment while accounting for a **semi-annual salary raise**. Every **6 months**, the yearly salary increases by the given percentage.

### User Inputs
Prompt the user for inputs in this order (cast to `float`):
1. `yearly_salary`
2. `portion_saved`
3. `cost_of_dream_home`
4. `semi_annual_raise`

### Solution
```python
# User inputs
yearly_salary = float(input("Enter your yearly salary: "))
portion_saved = float(input("Enter the portion of salary to save (decimal): "))
cost_of_dream_home = float(input("Enter the cost of your dream home: "))
semi_annual_raise = float(input("Enter the semi-annual raise (decimal): "))

# Constants
portion_down_payment = 0.25
annual_return = 0.04

# Calculations
monthly_salary = yearly_salary / 12
current_savings = 0
months = 0
down_payment = portion_down_payment * cost_of_dream_home

# Savings loop
while current_savings < down_payment:
    current_savings += current_savings * (annual_return / 12)
    current_savings += monthly_salary * portion_saved
    months += 1

    # Salary increases every 6 months
    if months % 6 == 0:
        yearly_salary += yearly_salary * semi_annual_raise
        monthly_salary = yearly_salary / 12

print("Number of months:", months)
```

## 🎯 Challenge: Dream House Savings – Part C

### Objective
Find the **minimum annual rate of return (`r`)** required to save enough money for the down payment on a dream house in **36 months (3 years)** using **bisection search**.

### User Input
Read input and cast to `float`:
1. `initial_deposit`

### Assumptions
- House cost = **$800,000**
- Down payment = **25%** ($200,000)
- Saving period = **36 months**
- Savings earn **monthly compound interest**
- Acceptable error = **±$100**
- Search range for `r`: **0.0** to **1.0** (0%–100%)

### Formula
$$\text{amount saved} = \text{initial deposit} \times \left(1 + \frac{r}{12}\right)^{\text{months}}$$

### Solution
```python
# Read the initial deposit
initial_deposit = float(input("Enter the initial deposit: "))

# Constants
house_cost = 800000
down_payment = house_cost * 0.25
months = 36
tolerance = 100

# Search range for annual return (0% to 100%)
low = 0.0
high = 1.0

steps = 0

while True:
    steps += 1

    # Find the middle rate
    r = (low + high) / 2

    # Calculate savings after 36 months
    amount_saved = initial_deposit * (1 + r / 12) ** months

    # Stop if savings are close enough to the target
    if abs(amount_saved - down_payment) <= tolerance:
        break

    # Increase the rate if savings are too low
    if amount_saved < down_payment:
        low = r
    # Decrease the rate if savings are too high
    else:
        high = r

# Display the result
print("Best annual rate of return:", r)
print("Steps in bisection search:", steps)
```

### Sample Output
```text
Enter the initial deposit: 150000

Best annual rate of return: 0.0826
Steps in bisection search: 14
```

## 🔑 Key Takeaways

| Concept | Key Point |
| :--- | :--- |
| **`while` loop** | Repeats while condition is `True` — beware of infinite loops |
| **`for` loop** | Iterates over sequences (strings, `range()`) |
| **`range(start, stop, step)`** | Generates integers — `stop` is **exclusive** |
| **`break`** | Exits the loop immediately |
| **`continue`** | Skips the rest of the current iteration |
| **`for...else`** | `else` block runs **only if no `break`** occurred |
| **Bisection Search** | Halves the search space each step — $\mathcal{O}(\log N)$ |
