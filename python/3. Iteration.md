## 💡 Motivation for Iteration

> *"If you keep going right, you are stuck in the same spot forever; to exit, take a chance and go the opposite way."*

Programs need a way to execute actions repeatedly until a specific condition changes. In programming, this is called **iteration** (or looping).

---

## 🔁 Loops in Python

A **loop** executes a block of code **repeatedly** based on a condition or over a sequence.

### 1. `while` Loop

Repeats a block of code **while a condition evaluates to `True`**.

**Syntax**
```python
while condition:
    # code block executed as long as condition is True
```

**Example: Countdown Timer**
```python
seconds = 3

while seconds > 0:
    print(seconds)
    seconds -= 1   # Important: change the variable to avoid an infinite loop!

print("Time's up!")
```

> [!WARNING]
> If the condition never becomes `False`, it creates an **infinite loop**.
> ```python
> while True:
>     print("Forever") # This will never stop!
> ```

---

### 2. `for` Loop

Used to iterate over a **sequence** (such as a string or a generated sequence of numbers).

**Syntax**
```python
for item in sequence:
    # code block executed for each item
```

**Example: Iterating over a string**
```python
for ch in "Python":
    print(ch)
```

> [!NOTE]
> **`in`** is a **membership operator** used to extract items from a sequence one by one.

---

## 🔢 `range()` Function

Generates an arithmetic sequence of numbers (commonly used with `for` loops).

**Syntax**
```python
range(start, stop, step)
```

### Parameters
- `start` *(default = 0)* → Starting number (inclusive)
- `stop` → Ending number (**exclusive**)
- `step` *(default = 1)* → Increment value

**Examples**
```python
# Stop only (0 to 4)
for i in range(5):
    print(i, end=" ")  # 0 1 2 3 4

# Start and Stop (2 to 5)
for i in range(2, 6):
    print(i, end=" ")  # 2 3 4 5

# Start, Stop, and Step
for i in range(1, 6, 2):
    print(i, end=" ")  # 1 3 5
```

### ⚡ Pythonic Shortcut: The Throwaway Variable `_`

Sometimes you need to run a loop a certain number of times, but you **don't actually care about the loop variable**.

```python
# ❌ Longer Approach
for i in range(3):
    print("Hello!") # 'i' is never used!

# ✅ Pythonic Approach
for _ in range(3):
    print("Hello!")
```
> [!TIP]
> In Python, a single underscore `_` is conventionally used to indicate a "throwaway" or unused variable. It makes the code cleaner by signaling to other developers: *"I just need to repeat this, I don't need the number."*

## 🛑 Loop Control Statements

### `break`
Stops the loop **immediately** and jumps to the code following the loop.

```python
for i in range(5):
    if i == 3:
        break
    print(i)  # Prints 0, 1, 2
```

---

### `continue`
Skips the **rest of the current iteration** and jumps to the next evaluation step.

```python
for i in range(5):
    if i == 2:
        continue
    print(i)  # Prints 0, 1, 3, 4
```

## 🔄 The `for...else` Pattern

Python has a unique feature where you can attach an `else` block to a loop.

> [!IMPORTANT]
> The `else` block executes **only if the loop finishes normally** (i.e., without hitting a `break`).

```python
# Normal completion
for i in range(3):
    print(i)
else:
    print("Finished successfully") 
# Output: 0, 1, 2, Finished successfully

# Broken completion
for i in range(3):
    if i == 1:
        break
    print(i)
else:
    print("Finished successfully")
# Output: 0 (The else block is skipped!)
```

## 🐛 Progressive Debugging: Tracing & Off-By-One Errors

When working with loops, the most common logical bug is the **Off-By-One Error (OBOE)**. This happens when a loop runs one time too many or one time too few.

### Identifying the Bug
Imagine we want to print numbers from 1 to 3.

```python
# BUGGY CODE
count = 1
while count < 3:
    print(count)
    count += 1
```
*Output: 1, 2. (It missed 3!)*

### How to Fix: Use a Trace Table
To debug loops, write out a **Trace Table** on paper to track variable states at the start of each iteration.

| Iteration | `count` at start | Condition (`count < 3`) | Action | `count` at end |
| :--- | :--- | :--- | :--- | :--- |
| 1st | 1 | `1 < 3` (True) | Prints 1 | 2 |
| 2nd | 2 | `2 < 3` (True) | Prints 2 | 3 |
| 3rd | 3 | `3 < 3` (False) | **Loop Ends** | 3 |

By tracing, we see the loop stops when `count` is 3. 
**Fix:** Change the condition to `count <= 3` or `count < 4`.

## 🧪 Self-Check Questions & Quizzes

### Question 1: The Loop Variable Trap 🔥 (Tricky)

What does this code output? Does it cause an infinite loop?
```python
for i in range(3):
    print(i)
    i = 10
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
0
1
2
```
*(No infinite loop!)*

#### 🔍 Explanation
In a `for` loop, the loop variable `i` is **re-assigned** by the iterator (`range(3)`) at the start of every single pass. 
1. Iteration 1: `range` yields `0`. `i = 0`. You print `0`. You assign `i = 10`.
2. Iteration 2: `range` yields `1`. `i` is immediately overwritten from `10` to `1`. You print `1`. You assign `i = 10`.
3. Iteration 3: `range` yields `2`. `i` is overwritten to `2`...

You cannot manually skip or alter a `for` loop's progression by modifying the target variable inside the loop body!
</details>

### Question 2: The `for...else` Interview Trap 💼 (Interview)

What does this code output?
```python
for ch in "Code":
    if ch == "x":
        print("Found x!")
        break
else:
    print("No x found.")
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution
```text
No x found.
```

#### 🔍 Explanation
The loop checks each character but never finds `"x"`. Because `break` is never executed, the loop finishes *normally*. A normal finish triggers the `else` block. 
This pattern is heavily tested in interviews because it elegantly replaces the need for a boolean "flag" variable (e.g., `found = False`).
</details>

### Question 3: Off-By-One Debugging 🐛 (Debugging)

The goal of this code is to add the numbers 1, 2, 3, 4, and 5. Why is the total `10` instead of `15`?
```python
total = 0
for i in range(1, 5):
    total += i
print(total)
```

<details>
<summary><b>💡 Click to Reveal Solution & Explanation</b></summary>

#### ✅ Solution & Fix
The `stop` parameter in `range()` is **exclusive**. `range(1, 5)` generates `1, 2, 3, 4`. It stops before `5`.

**Fix:** Change the range to `range(1, 6)`.
</details>

## 🏗️ Real-World Challenge: Dream House Savings

### 📌 Problem Statement – Part A
You are saving for a down payment on a dream house. The down payment is **25%** of the house cost. Write a script to calculate how many **months** it takes to save the required amount.

Your savings earn a monthly return of `annual_return / 12`. (Assume `annual_return = 0.04`).

**Inputs Needed:**
- Yearly salary (`yearly_salary`)
- Portion of salary saved each month (`portion_saved` as a decimal)
- Total cost of the home (`cost_of_dream_home`)

### 🧠 Systematic Problem-Solving Framework

<details>
<summary><b>1. Break Down & Pseudocode</b></summary>

1. Initialize `current_savings = 0` and `months = 0`.
2. Calculate `down_payment = cost * 0.25`.
3. Calculate `monthly_salary = yearly_salary / 12`.
4. Loop **while** `current_savings < down_payment`:
   - Add investment returns: `current_savings += current_savings * (0.04 / 12)`
   - Add monthly contribution: `current_savings += monthly_salary * portion_saved`
   - Increment `months += 1`
5. Print total `months`.
</details>

<details>
<summary><b>2. Implementation</b></summary>

```python
yearly_salary = float(input("Enter your yearly salary: "))
portion_saved = float(input("Enter the portion of salary to save (decimal): "))
cost_of_dream_home = float(input("Enter the cost of your dream home: "))

portion_down_payment = 0.25
annual_return = 0.04

monthly_salary = yearly_salary / 12
current_savings = 0.0
months = 0
down_payment = portion_down_payment * cost_of_dream_home

while current_savings < down_payment:
    current_savings += current_savings * (annual_return / 12)
    current_savings += monthly_salary * portion_saved
    months += 1

print("Number of months:", months)
```
</details>

### 📌 Problem Statement – Part B (Adding Branching)
Realistically, your salary increases over time! Modify your code so that every **6 months**, your `yearly_salary` increases by a given percentage (`semi_annual_raise`).

<details>
<summary><b>Implementation (Try adding the raise logic!)</b></summary>

```python
yearly_salary = float(input("Enter your yearly salary: "))
portion_saved = float(input("Enter the portion of salary to save (decimal): "))
cost_of_dream_home = float(input("Enter the cost of your dream home: "))
semi_annual_raise = float(input("Enter the semi-annual raise (decimal): "))

portion_down_payment = 0.25
annual_return = 0.04

monthly_salary = yearly_salary / 12
current_savings = 0.0
months = 0
down_payment = portion_down_payment * cost_of_dream_home

while current_savings < down_payment:
    current_savings += current_savings * (annual_return / 12)
    current_savings += monthly_salary * portion_saved
    months += 1

    # Apply raise every 6 months using the modulo operator!
    if months % 6 == 0:
        yearly_salary += yearly_salary * semi_annual_raise
        monthly_salary = yearly_salary / 12

print("Number of months:", months)
```
</details>

## 🔑 Key Takeaways

| Concept | Key Point |
| :--- | :--- |
| **`while` loop** | Repeats while condition is `True` — beware of infinite loops |
| **`for` loop** | Iterates over sequences (strings, `range()`) |
| **`range(start, stop, step)`** | Generates integers — `stop` is **exclusive** |
| **`break`** | Exits the loop immediately |
| **`continue`** | Skips the rest of the current iteration |
| **`for...else`** | `else` block runs **only if no `break`** occurred |
| **Tracing** | Manually writing out variable states step-by-step catches off-by-one errors |
