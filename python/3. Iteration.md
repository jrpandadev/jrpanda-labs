# 🔁 Loops in Python

A **loop** executes a block of code **repeatedly**.

## Types of Loops

### 1. `while` Loop
- Repeats **while a condition is `True`**.

**Syntax**
```python
while condition:
    # code block
```

**Example**
```python
i = 1

while i <= 3:
    print(i)
    i += 1
```

> [!WARNING]
> If the condition is always `True`, it creates an **infinite loop**.
>
> ```python
> while True:
>     # Infinite loop
> ```

## Challenge: Countdown Timer

**Problem Statement:**

Create a program that simulates a countdown timer.

### Functionality:
- Prompt the user to enter a starting time in **seconds**.
- Use a **`while` loop** with a counter variable.
- Inside the loop:
  - Print the remaining time.
  - Decrement the counter by **1** (simulating one second passing).
- Once the counter reaches **0**, print:
  ```
  Time's up!
  ```
- **Note:** `time.sleep(1)` may not be available in all environments, so include it only as a comment.

### Solution

```python
# Countdown Timer

# Prompt the user to enter the starting time in seconds
seconds = int(input("Enter the countdown time (in seconds): "))

# Continue the countdown until it reaches 0
while seconds > 0:
    print(seconds)

    # Simulate a 1-second delay
    # time.sleep(1)

    # Decrement the counter
    seconds -= 1

# Countdown finished
print("Time's up!")
```

---

### Loop Control Statements

#### `break`
- **Stops** the loop immediately.

```python
for i in range(5):
    if i == 3:
        break
    print(i)
```

#### `continue`
- **Skips** the current iteration and moves to the next.

```python
for i in range(5):
    if i == 2:
        continue
    print(i)
```

---

## 2. `for` Loop

- Used to iterate over a **sequence** (list, tuple, string, or `range()`).

**Syntax**
```python
for item in sequence:
    # code block
```

**Example**
```python
for ch in "Python":
    print(ch)
```

> **`in`** is a **membership operator** used to iterate over or check membership in a sequence.

---

## `range()` Function

Generates a sequence of numbers (commonly used with `for` loops).

**Syntax**
```python
range(start, stop, step)
```

### Parameters
- `start` *(default = 0)* → Starting number
- `stop` → Ending number (**not included**)
- `step` *(default = 1)* → Increment value

**Example**
```python
for i in range(1, 6, 2):
    print(i)
```

**Output**
```text
1
3
5
```

# Challenge: Dream House Savings – Part A

## Objective

Determine the number of **months** required to save enough money for the **down payment** on a dream house.

The down payment is **25% of the total cost** of the house.

---

## User Inputs

Prompt the user to enter the following values **(in this order)** and cast them to `float`.

1. `yearly_salary`
2. `portion_saved`
3. `cost_of_dream_home`

---

## Solution

```python
# User inputs
yearly_salary = float(input("Enter your yearly salary: "))
portion_saved = float(input("Enter the portion of salary to save (decimal): "))
cost_of_dream_home = float(input("Enter the cost of your dream home: "))

# Constants
portion_down_payment = 0.25
annual_return = 0.04

# Calculations
monthly_salary = yearly_salary / 12
current_savings = 0
months = 0
down_payment = portion_down_payment * cost_of_dream_home

# Savings loop
while current_savings < down_payment:
    current_savings += current_savings * (annual_return / 12)
    current_savings += monthly_salary * portion_saved
    months += 1

print("Number of months:", months)
```

# Challenge: Dream House Savings – Part B

## Objective

Calculate the number of **months** required to save enough money for the **down payment** on a dream house while accounting for a **semi-annual salary raise**.

Every **6 months**, the yearly salary increases by the given percentage.

---

## User Inputs

Prompt the user to enter the following values **(in this order)** and cast them to `float`.

1. `yearly_salary`
2. `portion_saved`
3. `cost_of_dream_home`
4. `semi_annual_raise`

---

## Solution

```python
# User inputs
yearly_salary = float(input("Enter your yearly salary: "))
portion_saved = float(input("Enter the portion of salary to save (decimal): "))
cost_of_dream_home = float(input("Enter the cost of your dream home: "))
semi_annual_raise = float(input("Enter the semi-annual raise (decimal): "))

# Constants
portion_down_payment = 0.25
annual_return = 0.04

# Calculations
monthly_salary = yearly_salary / 12
current_savings = 0
months = 0
down_payment = portion_down_payment * cost_of_dream_home

# Savings loop
while current_savings < down_payment:
    current_savings += current_savings * (annual_return / 12)
    current_savings += monthly_salary * portion_saved
    months += 1

    # Salary increases every 6 months
    if months % 6 == 0:
        yearly_salary += yearly_salary * semi_annual_raise
        monthly_salary = yearly_salary / 12

print("Number of months:", months)
```

# Challenge: Dream House Savings – Part C

## Objective

Find the **minimum annual rate of return (`r`)** required to save enough money for the **down payment** on a dream house in **36 months (3 years)** using **bisection search**.

---

## User Input

Read the following input and cast it to `float`:

1. `initial_deposit`

---

## Assumptions

- House cost = **$800,000**
- Down payment = **25%** of the house cost
- Saving period = **36 months**
- Savings earn **monthly compound interest**
- Acceptable error = **±$100**
- Annual rate of return (`r`) is between **0.0** and **1.0** (0%–100%)

---

## Compound Interest Formula

```text
amount_saved = initial_deposit × (1 + r / 12)^months
```

### Python Formula

```python
amount_saved = initial_deposit * (1 + r / 12) ** months
```

Where:
- `initial_deposit` → Initial amount in the savings account
- `r` → Annual rate of return
- `12` → Monthly compounding
- `months` → Total number of months (36)
- `**` → Power (exponent) operator

---

## Solution

```python
# Read the initial deposit
initial_deposit = float(input("Enter the initial deposit: "))

# Constants
house_cost = 800000
down_payment = house_cost * 0.25
months = 36
tolerance = 100

# Search range for annual return (0% to 100%)
low = 0.0
high = 1.0

steps = 0

while True:
    steps += 1

    # Find the middle rate
    r = (low + high) / 2

    # Calculate savings after 36 months
    amount_saved = initial_deposit * (1 + r / 12) ** months

    # Stop if savings are close enough to the target
    if abs(amount_saved - down_payment) <= tolerance:
        break

    # Increase the rate if savings are too low
    if amount_saved < down_payment:
        low = r

    # Decrease the rate if savings are too high
    else:
        high = r

# Display the result
print("Best annual rate of return:", r)
print("Steps in bisection search:", steps)
```
